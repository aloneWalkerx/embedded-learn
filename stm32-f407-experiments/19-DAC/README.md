# 实验 19：DAC输出

本实验通过 STM32F407ZGT6 的 **DAC1（通道 1，PA4）** 输出可调模拟电压，并通过 **ADC2（通道 1，PA1）** 回读验证输出电压的准确性。DAC 将数字量（0~4095）转换为模拟电压（0~3.3V），按键调节输出电压，LCD 实时显示 DAC 设定值和 ADC 回读值，形成 **"数字设定 → 模拟输出 → 数字回读"** 的完整闭环。

### ① 时钟树

> **目标**：理解 DAC 外设的时钟来源与配置。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    STM32F407 时钟树（DAC 部分）                            │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【DAC 时钟路径】                                                            │
│                                                                              │
│  ┌──────────────────────────────────────────────────────────────────────┐    │
│  │                    APB1 总线                                        │    │
│  │   PPRE1=4 → PCLK1 = 42MHz                                          │    │
│  │   DAC 挂载在 APB1 上                                               │    │
│  │   → DAC 时钟 = 42MHz                                              │    │
│  └──────────────────────────────────────────────────────────────────────┘    │
│         │                                                                    │
│         ▼                                                                    │
│  ┌──────────────────────────────────────────────────────────────────────┐    │
│  │                    DAC 核心                                          │    │
│  │   12 位数字值（0~4095）→ 模拟电压（0~VREF+）                       │    │
│  │   转换时间（建立时间）：约 3~5µs                                   │    │
│  │   输出引脚：PA4（DAC1）或 PA5（DAC2）                              │    │
│  └──────────────────────────────────────────────────────────────────────┘    │
│                                                                              │
│  【配合使用的 ADC 时钟】                                                     │
│                                                                              │
│  APB2（84MHz）→ ADC2 预分频器（/4）→ 21MHz → ADC2 核心                    │
│                                                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│  关键配置：                                                                  │
│  ┌─────────────────────┬────────────────────────────────────────────────┐   │
│  │ DAC 时钟            │ APB1（42MHz）                                 │   │
│  │ DAC 分辨率          │ 12 位（0~4095）                               │   │
│  │ DAC 输出引脚        │ PA4（DAC1 通道 1）                            │   │
│  │ 输出电压范围        │ 0 ~ 3.3V（VREF+ 决定）                        │   │
│  │ 触发方式            │ 软件触发（立即更新）                          │   │
│  │ 输出缓冲器          │ ENABLE（降低输出阻抗）                        │   │
│  └─────────────────────┴────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────────┘
```

#### 与前面实验的时钟对比

| 实验             | 核心外设     | 主要时钟源           | 用途             |
| -------------- | -------- | --------------- | -------------- |
| 实验 14（ADC）     | ADC2     | APB2（21MHz）     | 模拟电压 → 数字量     |
| 实验 16（温度传感器）   | ADC1     | APB2（21MHz）     | 采集芯片温度         |
| **实验 17（DAC）** | **DAC1** | **APB1（42MHz）** | **数字量 → 模拟电压** |

> **核心特点**：DAC 是 STM32F4 中**唯一不需要复杂时钟配置即可输出模拟信号**的外设，只需使能时钟即可工作。

### ② 寄存器级

> **目标**：从寄存器层面理解 DAC 的工作原理。

#### DAC 核心寄存器

| 寄存器             | 作用           | 本实验配置                    |
| --------------- | ------------ | ------------------------ |
| **DAC_CR**      | 控制寄存器        | 使能 DAC 通道 1、软件触发、使能输出缓冲器 |
| **DAC_DHR12R1** | 12 位右对齐数据寄存器 | 写入 0~4095 的值，自动转换为模拟电压   |
| **DAC_DOR1**    | 数据输出寄存器      | 读取当前 DAC 输出值（只读）         |
| **DAC_SR**      | 状态寄存器        | 检查 DAC 忙标志               |

#### DAC 输出电压计算公式

```
输出电压 = (DAC_Value / 4095) × VREF+
示例：
 DAC_Value = 2048 → 输出电压 = 2048/4095 × 3.3V ≈ 1.65V
 DAC_Value = 0 → 输出电压 = 0V
 DAC_Value = 4095 → 输出电压 = 3.3V
```

#### DAC 输出缓冲器

| 设置                            | 效果                       | 适用场景      |
| ----------------------------- | ------------------------ | --------- |
| **`DAC_OUTPUTBUFFER_ENABLE`** | 输出阻抗低（约 10kΩ），驱动能力强      | **本实验使用** |
| `DAC_OUTPUTBUFFER_DISABLE`    | 输出阻抗高（约 15kΩ），驱动能力弱，精度略高 | 高精度、低负载场景 |

### ③ 数据流

> **目标**：理清“按键 → DAC 输出 → ADC 回读 → LCD 显示”的完整数据流。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    DAC + ADC 完整数据流                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【用户操作层】                                                             │
│                                                                             │
│  按键 WK_UP 或 KEY0 → key_i_scan() 检测按键                               │
│       │                                                                     │
│       ├── WK_UP 按下 → dac_voltage += 100（增加 0.1V）                    │
│       └── KEY0 按下 → dac_voltage -= 100（减少 0.1V）                     │
│                                                                             │
│  【DAC 输出层】                                                             │
│                                                                             │
│  dac_set_voltage(dac_voltage)                                               │
│       │                                                                     │
│       ├── value = (dac_voltage × 4095) / 3300（数字量换算）               │
│       └── HAL_DAC_SetValue() → 写入 DAC_DHR12R1 寄存器 → PA4 输出模拟电压  │
│                                                                             │
│  【物理层】                                                                 │
│                                                                             │
│  PA4（DAC 输出）→ 杜邦线短接 → PA1（ADC 输入）                            │
│                                                                             │
│  【ADC 回读层】                                                             │
│                                                                             │
│  adc_get_result_average(ADC_CHANNEL_1, 10)                                 │
│       │                                                                     │
│       ├── 采样 10 次取平均（均值滤波）                                     │
│       └── 返回 ADC 值（0~4095）                                            │
│                                                                             │
│  【显示层】                                                                 │
│                                                                             │
│  DAC_CH1_VAL: 2048      ← HAL_DAC_GetValue() 读取                         │
│  DAC_CH1_VOL: 1.650V    ← dac_voltage / 1000（设定值）                    │
│  ADC2_CH1_VOL: 1.648V   ← ADC 回读值换算                                  │
│                                                                             │
│  ★ 理想情况下：DAC_CH1_VOL ≈ ADC2_CH1_VOL                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### ④ 中断/DMA 机制

> **目标**：理解本实验的 DAC + ADC 采集方式。

#### 本实验的方案：无中断，无 DMA，纯轮询

| 机制      | 是否使用 | 说明                  |
| ------- | ---- | ------------------- |
| **中断**  | 否    | DAC 软件触发更新，ADC 轮询读取 |
| **DMA** | 否    | 温度变化慢，无需 DMA        |

#### 为什么不用 DMA？

| 对比项          | 本实验（轮询）    | 使用 DMA        |
| ------------ | ---------- | ------------- |
| **DAC 更新频率** | 按键触发（极低）   | 定时器触发（高频）     |
| **ADC 采样频率** | 每 200ms 一次 | 连续高速采样        |
| **CPU 占用**   | < 0.3%     | 接近 0%         |
| **适用场景**     | 手动调节电压     | **音频播放、波形生成** |

> **结论**：在手动调节电压的场景下，轮询方式完全够用，无需 DMA

### ⑤ 改参实验

#### 改参实验 1：修改 DAC 初始电压

**操作**：在 `main.c` 中修改 `dac_voltage` 初始值。

```
// 修改前（0.1V，太小）
uint16_t dac_voltage = 100;
// 修改后（1.65V，中间值）
uint16_t dac_voltage = 1650;

**现象**：上电后 PA4 输出 1.65V，更易观察。

**结论**：初始电压可根据实际需求设置。
```

---

#### 改参实验 2：修改按键调节步长

**操作**：在按键处理中修改步长值。

```
// 修改前（0.1V）
dac_voltage += 100;
// 修改后（0.5V）
dac_voltage += 500;
```

**现象**：每次按键电压变化幅度增大。

**结论**：步长决定调节精度和速度，可根据需求调整。

---

#### 改参实验 3：修改 DAC 输出缓冲器

**操作**：在 `HAL_DAC_MspInit` 中修改 `DAC_OutputBuffer` 参数。

```
// 修改前
dac_channel_conf_struct.DAC_OutputBuffer = DAC_OUTPUTBUFFER_ENABLE;
// 修改后
dac_channel_conf_struct.DAC_OutputBuffer = DAC_OUTPUTBUFFER_DISABLE;
```

**现象**：输出驱动能力变弱，接负载时电压可能跌落。

**结论**：一般使用 ENABLE 以获得更好的驱动能力。

---

#### 改参实验 4：生成三角波（结合函数）

**操作**：在 `main.c` 中调用三角波函数。

```
// 在 main 循环之前或按键触发时调用
dac_triangular_wave(2048, 100, 100, 5); // 峰值 2048，间隔 100µs，100 个点，5 个周期
```

**现象**：PA4 输出三角波信号，用示波器可看到波形。

**结论**：DAC + 定时器 + DMA 可生成任意波形。
