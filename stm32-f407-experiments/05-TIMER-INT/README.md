# 实验 5：基本定时器中断

本实验通过STM32F407ZGT6板载的TIM6基本定时器控制LED1每隔一秒闪烁一次（====底部有实验结果视频====）



### ① 时钟树

> **目标**：理解基本定时器 TIM6 的时钟来源与配置方式。

**关键理解**：

- TIM6 挂载在 **APB1 总线**上，PCLK1 = 42MHz。

- STM32F4 系列中，挂载在 APB1 上的定时器，其**实际时钟 = APB1 时钟 × 2**（当 APB1 预分频系数 ≠ 1 时）。

- 因此 TIM6 的时钟 = 42MHz × 2 = **84MHz**。

- TIM6 是 **16 位** 定时器，因此 `PSC` 和 `ARR` 的最大值均为 65535。

### ② 寄存器级

> **目标**：从寄存器层面理解 TIM6 的配置与中断触发过程。

#### TIM6 核心寄存器

| 寄存器           | 全称          | 作用                      | 本实验配置           |
| ------------- | ----------- | ----------------------- | --------------- |
| **TIM6_PSC**  | 预分频寄存器      | 对 84MHz 时钟进行分频          | 8400 - 1 = 8399 |
| **TIM6_ARR**  | 自动重装载寄存器    | 设定计数终点值                 | 5000 - 1 = 4999 |
| **TIM6_CR1**  | 控制寄存器 1     | 计数器使能（CEN）、计数方向等        | CEN = 1（使能计数）   |
| **TIM6_DIER** | DMA/中断使能寄存器 | UIE = 1（使能更新中断）         | UIE = 1         |
| **TIM6_SR**   | 状态寄存器       | UIF（更新中断标志，硬件置 1，软件清 0） | 在 ISR 中自动清 0    |

#### 定时器配置的寄存器级操作

// 1. 使能 TIM6 时钟（RCC_APB1ENR bit4）
RCC->APB1ENR |= (1 << 4);
// 2. 设置预分频器（PSC）
TIM6->PSC = 8400 - 1;   // 分频后频率 = 84MHz / 8400 = 10kHz
// 3. 设置自动重装载值（ARR）
TIM6->ARR = 5000 - 1;   // 计数 5000 次溢出
// 4. 使能更新中断（DIER 的 UIE 位）
TIM6->DIER |= (1 << 0);  // UIE = 1
// 5. 启动计数器（CR1 的 CEN 位）
TIM6->CR1 |= (1 << 0);   // CEN = 1
// 6. 在中断服务函数中，硬件自动置位 UIF 标志
//    软件通过 HAL_TIM_IRQHandler 自动清除

#### 计数过程

计数时钟 = 84MHz / 8400 = 10kHz（每 0.1ms 计 1 次）
计数序列：0 → 1 → 2 → ... → 4999 → 溢出 → 0 → 1 → ...
溢出周期：5000 × 0.1ms = 500ms
中断频率：1 / 0.5s = 2Hz

### ④ 中断/DMA 机制

> **目标**：理解 TIM6 中断的工作机制及与 DAC 共享中断的注意事项。

#### 本实验方案：定时器更新中断

| 中断源            | 触发条件             | 标志位                  | 中断服务函数                |
| -------------- | ---------------- | -------------------- | --------------------- |
| **TIM6 更新中断**  | 计数器溢出（CNT = ARR） | UIF（TIM6_SR bit0）    | `TIM6_DAC_IRQHandler` |
| **DAC 中断（共享）** | DAC 下溢错误等        | DMAUDR（DAC_SR bit13） | `TIM6_DAC_IRQHandler` |

#### TIM6 与 DAC 共享中断

TIM6 和 DAC 共用同一个中断通道 `TIM6_DAC_IRQn`，因此也共用同一个中断服务函数 `TIM6_DAC_IRQHandler`。

**在 HAL 库中，底层已经自动处理了中断分流：**

c

// HAL 库内部实现（简化）
void TIM6_DAC_IRQHandler(void)
{
    // 判断是否是 TIM6 的更新中断
    if (__HAL_TIM_GET_FLAG(&htim6, TIM_FLAG_UPDATE) != RESET) {
        __HAL_TIM_CLEAR_FLAG(&htim6, TIM_FLAG_UPDATE);
        HAL_TIM_PeriodElapsedCallback(&htim6);
    }

    // 判断是否是 DAC 的中断
    if (__HAL_DAC_GET_FLAG(&hdac, DAC_FLAG_DMAUDR1) != RESET) {
        __HAL_DAC_CLEAR_FLAG(&hdac, DAC_FLAG_DMAUDR1);
        HAL_DAC_ErrorCallback(&hdac);
    }

}

**实际开发中的注意事项**：

| 场景                  | 问题                       | 建议                                               |
| ------------------- | ------------------------ | ------------------------------------------------ |
| **使用 TIM6 但不用 DAC** | DAC 的中断标志可能因复位状态不确定而意外触发 | 在 `HAL_DAC_ErrorCallback` 中加空实现，或使用 TIM7（独立中断通道） |
| **同时使用 TIM6 和 DAC** | 两个中断共享 NVIC 通道，优先级必须一起设置 | 合理分配优先级，避免互相阻塞                                   |
| **不想折腾 TIM6 共享中断**  | 希望彻底分开                   | 换用 TIM7（中断函数为 `TIM7_IRQHandler`，独立通道）            |



### ⑤ 改参实验

> **目标**：通过修改参数验证对定时器的理解。

#### 改参实验 1：修改中断周期（改变 ARR）

**操作**：将 `btim_timx_int_init(5000 - 1, 8400 - 1)` 改为 `btim_timx_int_init(1000 - 1, 8400 - 1)`。

**预期现象**：中断周期 = 1000 × 0.1ms = 100ms，LED1 闪烁速度加快 5 倍。

**结论**：`ARR` 控制计数器溢出的周期，`ARR` 越小，中断越频繁。

#### 改参实验 2：修改计数精度（改变 PSC）

**操作**：将 `btim_timx_int_init(5000 - 1, 8400 - 1)` 改为 `btim_timx_int_init(10000 - 1, 4200 - 1)`。

**计算**：

- PSC + 1 = 4200 → 分频后频率 = 84MHz / 4200 = 20kHz（0.05ms）

- ARR + 1 = 10000 → 中断周期 = 10000 × 0.05ms = 500ms

**预期现象**：中断周期保持不变（500ms），但计数精度提高了一倍。

**结论**：`PSC` 和 `ARR` 共同决定中断频率，两者乘积不变时，中断频率不变。

#### 改参实验 3：软件计数器派生更长周期

**操作**：在回调函数中加入软件计数器，数 4 次（2 秒）再翻转 LED。

static uint8_t cnt = 0;
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == BTIM_TIMX_INT) {
        cnt++;
        if (cnt >= 4) {      // 4 × 500ms = 2 秒
            cnt = 0;
            LED1_TOGGLE();   // 每 2 秒翻转一次
        }
    }
}

**预期现象**：LED1 以 2 秒为周期闪烁（亮 2 秒，灭 2 秒）。

**结论**：硬件定时器提供固定节拍，软件计数器派生任意时间周期。

#### 改参实验 4：在回调中添加多个独立周期

static uint8_t cnt_100ms = 0;
static uint8_t cnt_1s = 0;
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == BTIM_TIMX_INT) {
        cnt_100ms++;
        cnt_1s++;

        if (cnt_100ms >= 1) {   // 每 500ms（实验当前周期）
            cnt_100ms = 0;
            // 执行 500ms 任务
        }
    
        if (cnt_1s >= 2) {      // 每 1s
            cnt_1s = 0;
            // 执行 1s 任务
        }
    }

}

**结论**：一个硬件定时器可以派生出任意多个不同周期的时间基准。
