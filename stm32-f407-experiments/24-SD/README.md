# 实验 24：SD卡

本实验通过 STM32F407ZGT6 的 **SDIO（Secure Digital Input/Output）** 接口，驱动板载 **Micro SD 卡**，实现 SD 卡的初始化、信息读取和块数据读写。通过本实验，深入理解 **SDIO 协议**、**SD 卡的命令响应机制**、**4 位数据总线模式** 以及 **自定义内存管理（内存池）** 的应用。

### ① 时钟树

> **目标**：理解 SDIO 接口的时钟来源与配置。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    STM32F407 时钟树（SDIO 部分）                            │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【SDIO 时钟路径】                                                           │
│                                                                              │
│  ┌──────────────┐                                                            │
│  │  PLL 锁相环  │ → 48MHz（SDIO 专用时钟）                                  │
│  └──────┬───────┘                                                            │
│         │                                                                    │
│         ▼                                                                    │
│  ┌──────────────────────────────────────────────────────────────────────┐    │
│  │                    SDIO 时钟分频器                                  │    │
│  │   SDIOCLK = 48MHz                                                   │    │
│  │   SDIO_CK = SDIOCLK / (ClockDiv + 2)                               │    │
│  │   ★ 本实验 ClockDiv = 1 → SDIO_CK = 48MHz / 3 = 16MHz             │    │
│  │   ★ SD 卡最高支持 24MHz，16MHz 安全可靠                            │    │
│  └──────────────────────────────────────────────────────────────────────┘    │
│         │                                                                    │
│         ▼                                                                    │
│  ┌──────────────────────────────────────────────────────────────────────┐    │
│  │                    SDIO 接口                                        │    │
│  │   命令线（CMD）：发送命令，接收响应                                  │    │
│  │   数据线（D0~D3）：4 位并行传输，速度是 SPI 的 4 倍                │    │
│  └──────────────────────────────────────────────────────────────────────┘    │
│                                                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│  关键配置：                                                                  │
│  ┌─────────────────────┬────────────────────────────────────────────────┐   │
│  │ SDIO 时钟源          │ PLL 输出（48MHz）                             │   │
│  │ SDIO 工作频率        │ 16MHz（稳定可靠）                             │   │
│  │ 数据总线宽度         │ 4 位（D0~D3）                                 │   │
│  │ 通信模式            │ SDIO 模式（非 SPI 模式）                      │   │
│  │ 块大小              │ 512 字节（标准 SD 卡块大小）                  │   │
│  └─────────────────────┴────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────────┘
```

#### 与前面实验的时钟对比

| 实验               | 核心外设     | 主要时钟源          | 用途                |
| ---------------- | -------- | -------------- | ----------------- |
| 实验 19（SPI Flash） | SPI1     | APB2（84MHz）    | 驱动外部 Flash 芯片     |
| 实验 21（内部 Flash）  | FLASH    | 总线直接访问         | 芯片内部 Flash 读写     |
| **实验 22（SD 卡）**  | **SDIO** | **PLL（48MHz）** | **驱动 Micro SD 卡** |

### ② SD 卡基础概念

> **目标**：理解 SD 卡的基本结构和操作模式。

#### SD 卡引脚定义（SDIO 模式）

| SD 卡引脚 | 名称       | 方向  | 功能                   |
| ------ | -------- | --- | -------------------- |
| **1**  | **DAT3** | 双向  | **数据线 3**（初始化时用作 CS） |
| **2**  | **CMD**  | 双向  | **命令/响应线**           |
| **3**  | VSS1     | 电源  | **GND**              |
| **4**  | VDD      | 电源  | **3.3V 电源**          |
| **5**  | CLK      | 输入  | **时钟信号**（由主机产生）      |
| **6**  | VSS2     | 电源  | **GND**              |
| **7**  | DAT0     | 双向  | **数据线 0**            |
| **8**  | DAT1     | 双向  | **数据线 1**            |
| **9**  | DAT2     | 双向  | **数据线 2**            |

#### SDIO vs SPI 模式对比

| 对比项       | **SDIO 模式（本实验）**       | **SPI 模式**                  |
| --------- | ---------------------- | --------------------------- |
| **数据线宽度** | **4 位（D0~D3）**         | 1 位（MISO/MOSI）              |
| **传输速度**  | **快**（16MHz × 4 位）     | 慢（最高 25MHz × 1 位）           |
| **命令响应**  | 专用 CMD 线               | 共用 MOSI/MISO                |
| **引脚数量**  | 6 根（D0~D3 + CMD + CLK） | 4 根（CS + SCK + MOSI + MISO） |
| **硬件支持**  | 需要 SDIO 外设             | 任意 SPI 接口                   |
| **本实验使用** | ✅ **是**                | ❌                           |

#### SD 卡类型

| 类型       | 容量范围       | 寻址方式     | 说明        |
| -------- | ---------- | -------- | --------- |
| **SDSC** | ≤ 2GB      | **字节寻址** | 标准容量卡（老卡） |
| **SDHC** | 4GB ~ 32GB | **扇区寻址** | 高容量卡（最常见） |
| **SDXC** | 64GB ~ 2TB | **扇区寻址** | 扩展容量卡     |

#### SD 卡命令格式

```
SD 卡命令格式（48 位）：

  位 47~40  │  位 39~8  │  位 7~1  │  位 0
  ──────────┼───────────┼──────────┼─────────
  命令索引  │  参数     │   CRC7   │  停止位
  （6 位）  │ （32 位） │ （7 位） │ （1 位）
```

**常用命令**：

| 命令         | 值   | 说明                             |
| ---------- | --- | ------------------------------ |
| **CMD0**   | 0   | GO_IDLE_STATE（复位）              |
| **CMD8**   | 8   | SEND_IF_COND（电压检测）             |
| **ACMD41** | 41  | APP_CMD + SD_SEND_OP_COND（初始化） |
| **CMD17**  | 17  | READ_SINGLE_BLOCK（读单块）         |
| **CMD24**  | 24  | WRITE_SINGLE_BLOCK（写单块）        |
| **CMD55**  | 55  | APP_CMD（前缀命令）                  |

### ③ 寄存器级

> **目标**：从寄存器层面理解 SDIO 接口的配置。

#### SDIO 核心寄存器

| 寄存器             | 作用         | 本实验配置                      |
| --------------- | ---------- | -------------------------- |
| **SDIO_POWER**  | 电源控制寄存器    | 使能 SDIO 电源                 |
| **SDIO_CLKCR**  | 时钟控制寄存器    | 配置时钟分频（ClockDiv=1）、边沿（上升沿） |
| **SDIO_CMD**    | 命令寄存器      | 发送命令到 SD 卡                 |
| **SDIO_RESPx**  | 响应寄存器      | 存储 SD 卡的响应数据               |
| **SDIO_DCTRL**  | 数据传输控制寄存器  | 配置数据方向、块大小、传输模式            |
| **SDIO_DTIMER** | 数据超时寄存器    | 设置超时时间                     |
| **SDIO_DLEN**   | 数据长度寄存器    | 设置传输数据长度（字节）               |
| **SDIO_FIFO**   | FIFO 数据寄存器 | 传输数据 FIFO（32 位宽）           |

#### SDIO 初始化流程

```
HAL_SD_Init() 内部流程：

  ① CMD0（复位）→ 等待 SD 卡进入空闲状态
  ② CMD8（电压检测）→ 检查 SD 卡是否支持 2.7~3.6V
  ③ ACMD41（初始化）→ 获取卡容量和类型
  ④ CMD2（获取 CID）→ 读取卡标识
  ⑤ CMD3（获取 RCA）→ 分配相对卡地址
  ⑥ CMD9（获取 CSD）→ 读取卡特定数据
  ⑦ CMD7（选择卡）→ 选中 SD 卡
```

```

│                    SD 卡读操作完整数据流                                    │

│       │                                                                      │
│       └── sd_read_disk(buf, 0, 1)                                          │
│                                                                             │
```

### ⑤ 内存管理（自定义内存池）

> **目标**：理解本实验使用的自定义内存管理机制。

#### 为什么要用自定义内存管理？

| 原因         | 说明                              |
| ---------- | ------------------------------- |
| **避免内存碎片** | 标准 `malloc` 在长时间运行后容易产生碎片       |
| **指定内存区域** | 可将不同数据放入不同内存池（SRAM/CCM/外部 SRAM） |
| **提高速度**   | 固定块大小分配，速度快且时间可预测               |
| **裸机专用**   | 不依赖操作系统，适合单片机环境                 |

#### 三个内存池

| 内存池         | 位置      | 大小    | 特点                    |
| ----------- | ------- | ----- | --------------------- |
| **SRAMIN**  | 内部 SRAM | 100KB | CPU 和 DMA 都可访问（本实验使用） |
| **SRAMCCM** | CCM 内存  | 60KB  | **仅 CPU 可访问**，速度更快    |
| **SRAMEX**  | 外部 SRAM | 963KB | 容量大，速度较慢              |

#### 内存分配原理

```
内存池（100KB = 3200 块，每块 32 字节）
┌────┬────┬────┬────┬────┬────┬─────┬────┐
│块0 │块1 │块2 │块3 │块4 │块5 │ ... │块3199│
└────┴────┴────┴────┴────┴────┴─────┴────┘

管理表（3200 项）
┌────┬────┬────┬────┬────┬────┬─────┬────┐
│ 0  │ 0  │ 0  │ 0  │ 0  │ 0  │ ... │ 0  │
└────┴────┴────┴────┴────┴────┴─────┴────┘
  ↑
 0 = 空闲，非 0 = 已分配（值代表连续块数）

分配 100 字节 → 需要 4 块（100/32 = 3.125 → 向上取整）
管理表：
┌────┬────┬────┬────┬────┬────┐
│ 4  │ 4  │ 4  │ 4  │ 0  │ 0  │
└────┴────┴────┴────┴────┴────┘
  ↑      ↑      ↑      ↑
 全部填 4（表示这 4 块属于同一个分配）
```

### ⑥ 中断/DMA 机制

> **目标**：理解 SDIO 的数据传输方式。

#### 本实验的方案：**无中断，无 DMA，纯 CPU 轮询**

| 机制      | 是否使用 | 说明                               |
| ------- | ---- | -------------------------------- |
| **中断**  | 否    | 使用轮询等待状态位（HAL_SD_GetCardState）   |
| **DMA** | 否    | SDIO 读取通过 HAL 库阻塞方式，数据量小（512 字节） |

#### SDIO 传输状态机

```
HAL_SD_CARD_PROGRAMMING（编程中）
         │
         ▼
HAL_SD_CARD_RECEIVING（接收中）
         │
         ▼
HAL_SD_CARD_TRANSFER（传输完成，空闲）← ★ 轮询等待此状态
         │
         ▼
HAL_SD_CARD_READY（就绪）
```

### ⑦ 改参实验

#### 改参实验 1：修改 SDIO 时钟频率

**操作**：在 `sd_init()` 中修改 `ClockDiv` 参数。

```
// 修改前（16MHz）
g_sd_handle.Init.ClockDiv = 1;
// 修改后（12MHz，更稳定）
g_sd_handle.Init.ClockDiv = 2;
// 修改后（24MHz，最快）
g_sd_handle.Init.ClockDiv = 0;
```

**现象**：时钟越高，读写速度越快，但可能不稳定。

**结论**：SD 卡最高支持 24MHz，建议从 16MHz 开始测试。

---

#### 改参实验 2：读取不同块地址

**操作**：在 `sd_read_test()` 中修改读取地址。

```
// 修改前（第 0 块，MBR）
sd_read_disk(buf, 0, 1);
// 修改后（第 1 块）
sd_read_disk(buf, 1, 1);
// 修改后（第 100 块）
sd_read_disk(buf, 100, 1);
```

**现象**：读取不同扇区的数据。

**结论**：SD 卡按块（扇区）寻址，每块 512 字节。

---

#### 改参实验 3：读取多块数据

**操作**：修改 `count` 参数。

```
// 修改前（读取 1 块）
sd_read_disk(buf, 0, 1);
// 修改后（读取 5 块）
sd_read_disk(buf, 0, 5);
```

**现象**：连续读取 5 个块（2560 字节）。

**结论**：SDIO 支持多块连续读取，速度更高。

---

#### 改参实验 4：修改内存块大小

**操作**：在 `malloc.h` 中修改 `MEM1_BLOCK_SIZE`。

```
// 修改前（32 字节）
#define MEM1_BLOCK_SIZE 32
// 修改后（64 字节）
#define MEM1_BLOCK_SIZE 64
```



**现象**：内存利用率降低，但管理表更小。

**结论**：块大小是内存利用率和表大小的权衡。
