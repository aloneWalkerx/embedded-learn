# 实验 23：FLASH存储

本实验通过操作 STM32F407 芯片内部的 **1MB FLASH 存储器**，实现在程序代码区域之外的用户数据存储。与外部 SPI Flash（W25Q128）不同，内部 Flash 通过**总线直接访问**，具有**更快的读写速度**和**无需额外引脚**的优势，但擦除操作**可能影响程序代码**，需要谨慎选择存储扇区

### ② Flash 存储器结构

> **目标**：理解 STM32F407 内部 Flash 的扇区分布。

#### Flash 扇区分布表

| 扇区        | 起始地址           | 结束地址           | 大小        | 说明                |
| --------- | -------------- | -------------- | --------- | ----------------- |
| **扇区 0**  | 0x08000000     | 0x08003FFF     | 16KB      | ★ **存放程序代码（危险！）** |
| **扇区 1**  | 0x08004000     | 0x08007FFF     | 16KB      | ★ **存放程序代码（危险！）** |
| **扇区 2**  | 0x08008000     | 0x0800BFFF     | 16KB      | ★ **存放程序代码（危险！）** |
| **扇区 3**  | 0x0800C000     | 0x0800FFFF     | 16KB      | ★ **存放程序代码（危险！）** |
| **扇区 4**  | 0x08010000     | 0x0801FFFF     | 64KB      | ★ **存放程序代码（危险！）** |
| 扇区 5      | 0x08020000     | 0x0803FFFF     | 128KB     | ⚠️ 可能存放代码         |
| 扇区 6      | 0x08040000     | 0x0805FFFF     | 128KB     | ⚠️ 可能存放代码         |
| 扇区 7      | 0x08060000     | 0x0807FFFF     | 128KB     | ⚠️ 可能存放代码         |
| 扇区 8      | 0x08080000     | 0x0809FFFF     | 128KB     | ⚠️ 可能存放代码         |
| 扇区 9      | 0x080A0000     | 0x080BFFFF     | 128KB     | ⚠️ 可能存放代码         |
| **扇区 10** | **0x080C0000** | **0x080DFFFF** | **128KB** | ✅ **推荐使用**        |
| **扇区 11** | **0x080E0000** | **0x080FFFFF** | **128KB** | ✅ **推荐使用（本实验）**   |

#### 本实验使用的地址

```
// Flash 末地址（0x080FFFFF）
#define FLASH_END 0x080FFFFF
// 用户数据起始地址（末地址往前 20 字节）
#define USER_ADDR (FLASH_END + 1 - TEXT_SIZE)
// 例如：0x080FFFFF + 1 - 20 = 0x080FFFE0
```

### ③ 寄存器级

> **目标**：从寄存器层面理解 Flash 操作。

#### Flash 关键寄存器

| 寄存器            | 作用      | 本实验操作                         |
| -------------- | ------- | ----------------------------- |
| **FLASH_ACR**  | 访问控制寄存器 | 配置等待周期、缓存使能                   |
| **FLASH_KEYR** | 密钥寄存器   | 写入 0x45670123 + 0xCDEF89AB 解锁 |
| **FLASH_CR**   | 控制寄存器   | 配置擦除/编程操作                     |
| **FLASH_SR**   | 状态寄存器   | 检测 BUSY 位                     |

#### Flash 操作流程

```
解锁 Flash
    │
    ├── FLASH_KEYR = 0x45670123
    └── FLASH_KEYR = 0xCDEF89AB
    │
    ▼
擦除扇区
    │
    ├── FLASH_CR = 配置（扇区号、擦除类型）
    ├── FLASH_CR |= FLASH_CR_START
    └── 等待 FLASH_SR 的 BUSY 位清零
    │
    ▼
写入数据
    │
    ├── FLASH_CR |= FLASH_CR_PG（编程使能）
    ├── *(volatile uint32_t *)addr = data
    └── 等待 FLASH_SR 的 BUSY 位清零
    │
    ▼
锁住 Flash
    │
    └── FLASH_CR |= FLASH_CR_LOCK
```

### ④ 数据流

> **目标**：理清内部 Flash 写入与读取的数据流。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    内部 Flash 完整数据流                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【写入流程】（WKUP 键触发）                                                │
│                                                                             │
│  用户按 WKUP → 按键扫描检测                                                 │
│       │                                                                      │
│       ▼                                                                      │
│  flash_write(addr, (uint32_t *)wdata, 5)                                   │
│       │                                                                      │
│       ├── ① 检查地址合法性（是否在 Flash 范围、是否 4 字节对齐）            │
│       │                                                                      │
│       ├── ② 遍历目标地址，检查是否需要擦除                                  │
│       │   ├── 如果某个地址 != 0xFFFFFFFF → 需要擦除                        │
│       │   │   ├── 计算扇区号（flash_get_flash_sector）                      │
│       │   │   ├── 解锁 Flash（HAL_FLASH_Unlock）                           │
│       │   │   ├── 擦除扇区（HAL_FLASHEx_Erase）                            │
│       │   │   └── 锁住 Flash（HAL_FLASH_Lock）                             │
│       │   └── 如果全部是 0xFFFFFFFF → 跳过擦除                             │
│       │                                                                      │
│       └── ③ 写入数据                                                       │
│           ├── flash_write_nocheck(addr, buf, 1)                            │
│           │   ├── 解锁 Flash                                               │
│           │   ├── 禁用数据缓存                                             │
│           │   ├── HAL_FLASH_Program（写入 1 个字）                         │
│           │   ├── 启用数据缓存                                             │
│           │   └── 锁住 Flash                                               │
│           ├── addr += 4（下一个地址）                                      │
│           └── buf++（下一个数据）                                          │
│       │                                                                      │
│       ▼                                                                      │
│  LCD 显示 "Flash Write Finished!"                                           │
│                                                                             │
│  【读取流程】（KEY0 键触发）                                                │
│                                                                             │
│  用户按 KEY0 → 按键扫描检测                                                 │
│       │                                                                      │
│       ▼                                                                      │
│  flash_read(addr, (uint32_t *)data, 5)                                     │
│       │                                                                      │
│       └── 循环 5 次：                                                        │
│           ├── data[i] = flash_read_word(addr)                              │
│           │   └── return (*(volatile uint32_t *)addr)    // 直接指针读取   │
│           └── addr += 4                                                    │
│       │                                                                      │
│       ▼                                                                      │
│  LCD 显示读取到的数据 "STM32 FLASH TEST"                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### ⑤ 中断/DMA 机制

> **目标**：理解 Flash 操作的执行方式。

#### 本实验的方案：**无中断，无 DMA，纯 CPU 轮询**

| 机制      | 是否使用 | 说明                         |
| ------- | ---- | -------------------------- |
| **中断**  | 否    | Flash 编程/擦除使用轮询等待 BUSY 位清零 |
| **DMA** | 否    | 数据量小（5 个字），无需 DMA          |

#### Flash 编程等待机制

```
// HAL 库内部实现（简化）
while (__HAL_FLASH_GET_FLAG(FLASH_FLAG_BSY) != RESET)
{
    // 等待 BUSY 位清零（约 100~200ms）
}
```

### ⑥ 改参实验

#### 改参实验 1：修改存储地址（换扇区）

**操作**：修改 `main.c` 中的写入地址。

```
// 修改前（扇区 11，末尾 128KB）
#define USER_ADDR (FLASH_END + 1 - TEXT_SIZE)
// 修改后（扇区 10，0x080C0000 起始）
#define USER_ADDR 0x080C0000
```

**现象**：数据存储位置改变。

**结论**：可使用任一安全扇区（推荐扇区 10/11）。

---

#### 改参实验 2：修改写入数据内容

**操作**：修改 `g_text_buf` 字符串。

```
// 修改前
static const uint8_t g_text_buf[] = {"STM32 FLASH TEST"};
// 修改后
static const uint8_t g_text_buf[] = {"Hello STM32!"};
```

**现象**：写入和读取的内容改变。

**结论**：可存储任意用户数据。

---

#### 改参实验 3：不擦除直接写入

**操作**：注释掉擦除代码，直接调用 `flash_write_nocheck`。

**现象**：写入失败，读取到 0xFFFFFFFF 或数据错乱。

**结论**：**必须先擦除再写入**，这是 Flash 的物理特性。

---

#### 改参实验 4：写入超过 4 字节对齐的数据

**操作**：`TEXT_SIZE` 不进行 4 字节对齐。

```
// 修改前（对齐）
#define TEXT_SIZE (((sizeof(g_text_buf) >> 2) << 2) + 4)
// 修改后（不对齐）
#define TEXT_SIZE sizeof(g_text_buf) // 18 字节
```

**现象**：`flash_write` 地址检查失败，无法写入。

**结论**：内部 Flash 写入必须 **4 字节对齐**。
