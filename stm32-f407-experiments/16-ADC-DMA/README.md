# 实验 16：单通道ADC(DMA)

本实验通过 STM32F407ZGT6 的 **ADC3** 和 **DMA2** 配合，实现**无需 CPU 干预的连续自动采样**。ADC 持续转换，DMA 自动将数据搬运到内存缓冲区，CPU 仅在数据准备就绪时进行处理。

### ① 时钟树

> **目标**：理解 ADC + DMA 模式下的时钟配置。

│                    STM32F407 时钟树（ADC + DMA 部分）                       │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【ADC 时钟路径】                                                            │
│                                                                              │

│                                                                              │
│  【DMA 时钟路径】                                                            │
│                                                                              │

│  【协同工作流程】                                                            │
│                                                                              │

│       └── 搬运到内存缓冲区（g_adc_dma_buf[]）                               │

│  ┌─────────────────────┬────────────────────────────────────────────────┐   │

│  │ DMA 通道            │ Channel 2（ADC3 专用）                        │   │

#### 与轮询 ADC 实验的对比

| 对比项        | 轮询 ADC（实验 14） | ADC + DMA（实验 15）   |
| ---------- | ------------- | ------------------ |
| **ADC 外设** | ADC2          | **ADC3**           |
| **DMA 使用** | ❌ 不使用         | ✅ **DMA2_Stream1** |
| **采集模式**   | 单次转换          | **连续转换**           |
| **CPU 参与** | 每次都要等待        | **启动后完全释放**        |
| **数据存储**   | 单个变量          | **DMA 自动填充数组**     |
| **适用场景**   | 学习原理          | **实际产品（推荐）**       |

### ② 寄存器级

> **目标**：从寄存器层面理解 ADC + DMA 的配置。

#### ADC 寄存器（DMA 模式变化）

| 寄存器         | 位/字段              | 本实验配置              |
| ----------- | ----------------- | ------------------ |
| **ADC_CR2** | **CONT**（连续转换）    | **1**（连续模式）        |
| **ADC_CR2** | **DMA**（DMA 使能）   | **1**（使能 DMA）      |
| **ADC_CR2** | **DDS**（DMA 连续请求） | **1**（每次转换都请求 DMA） |

#### DMA 寄存器

| 寄存器            | 作用        | 本实验配置                     |
| -------------- | --------- | ------------------------- |
| **DMA_SxCR**   | 数据流控制寄存器  | 通道 2、外设→内存、16 位、内存递增      |
| **DMA_SxPAR**  | 外设地址寄存器   | `&ADC3->DR`（ADC3 数据寄存器地址） |
| **DMA_SxM0AR** | 内存地址寄存器 0 | `g_adc_dma_buf`（缓冲区首地址）   |
| **DMA_SxNDTR** | 传输数量寄存器   | `ADC_DMA_BUF_SIZE`（50）    |

#### DMA 映射表（ADC3）

| 外设请求     | DMA 控制器  | 数据流                         | 通道            | 说明             |
| -------- | -------- | --------------------------- | ------------- | -------------- |
| **ADC3** | **DMA2** | **Stream 0** 或 **Stream 1** | **Channel 2** | 本实验使用 Stream 1 |

### ③ 数据流

│                                                                             │

│                                                                             │

│       ▼                                                                      │

│  ★ 在 DMA 采集期间，CPU 完全自由！                                          │

### ④ 中断/DMA 机制

> **目标**：理解 DMA 传输完成中断的触发与处理流程。

#### DMA 中断类型

| 中断类型        | 触发条件           | 处理函数                           | 作用             |
| ----------- | -------------- | ------------------------------ | -------------- |
| **传输完成中断**  | DMA 搬完 N 个数据   | `HAL_ADC_ConvCpltCallback`     | 置位标志，通知主循环处理数据 |
| **半传输完成中断** | DMA 搬完 N/2 个数据 | `HAL_ADC_ConvHalfCpltCallback` | 可用于乒乓缓冲（本实验未用） |
| **传输错误中断**  | DMA 传输出错       | `HAL_ADC_ErrorCallback`        | 错误处理（本实验未用）    |

#### 与轮询 ADC 的中断对比

| 实验                 | 中断类型           | 触发频率            | CPU 参与度        |
| ------------------ | -------------- | --------------- | -------------- |
| 实验 14（轮询 ADC）      | 无中断（纯轮询）       | -               | 高（每次都要等待）      |
| **实验 15（ADC+DMA）** | **DMA 传输完成中断** | **每次采满 50 个数据** | **极低（仅中断时介入）** |

> **核心优势**：50 次采样才触发 1 次中断，中断频率降低了 50 倍！

### ⑤ 改参实验

> **目标**：通过修改参数验证对 ADC + DMA 的理解。

#### 改参实验 1：修改 DMA 缓冲区大小

**操作**：在 `main.c` 中修改 `ADC_DMA_BUF_SIZE` 宏。



// 修改前
#define ADC_DMA_BUF_SIZE    50
// 修改后
#define ADC_DMA_BUF_SIZE    100

**现象**：缓冲区变大，中断触发频率降低，平均值更稳定，但响应变慢。

**结论**：缓冲区大小是**稳定性与响应速度的权衡**。

---

#### 改参实验 2：修改 DMA 模式（普通 → 循环）

**操作**：在 `HAL_ADC_MspInit` 中修改 DMA 模式。

// 修改前
g_adc_dma_dma_handle.Init.Mode = DMA_NORMAL;
// 修改后
g_adc_dma_dma_handle.Init.Mode = DMA_CIRCULAR;

**现象**：DMA 填满缓冲区后自动从头继续填，无需重新调用 `adc_dma_enable()`。

**结论**：循环模式适合**持续不间断采样**（如音频、电机控制）。

---

#### 改参实验 3：切换 DMA 数据流（Stream 1 → Stream 0）

**操作**：在 `adc.h` 中修改宏定义。

// 修改前
#define ADC_DMA_ADCX_DMASX                      DMA2_Stream1
#define ADC_DMA_ADCX_DMASX_IRQn                 DMA2_Stream1_IRQn
#define ADC_DMA_ADCX_DMASX_IRQHandler           DMA2_Stream1_IRQHandler
// 修改后
#define ADC_DMA_ADCX_DMASX                      DMA2_Stream0
#define ADC_DMA_ADCX_DMASX_IRQn                 DMA2_Stream0_IRQn
#define ADC_DMA_ADCX_DMASX_IRQHandler           DMA2_Stream0_IRQHandler

**现象**：功能完全相同（ADC3 支持 Stream 0 和 Stream 1）。

**结论**：Stream 0 和 Stream 1 功能等价，选择哪个取决于工程需要。

---

#### 改参实验 4：修改采样时间

**操作**：在 `adc_dma_enable()` 中修改采样时间参数。

// 修改前（精度最高）
adc_channel_set(&g_adc_dma_handle, ADC_DMA_ADCX_CHY, 1, ADC_SAMPLETIME_480CYCLES);
// 修改后（速度最快）
adc_channel_set(&g_adc_dma_handle, ADC_DMA_ADCX_CHY, 1, ADC_SAMPLETIME_3CYCLES);

**现象**：采样时间变短，采样速度变快，但精度可能下降。

**结论**：采样时间需根据**信号源内阻**选择。

---

#### 改参实验 5：切换 ADC 外设

**操作**：在 `adc.h` 中修改 ADC 外设宏定义。

// 修改前（ADC3）
#define ADC_DMA_ADCX                            ADC3
// 修改后（ADC1，需查 DMA 映射表）
#define ADC_DMA_ADCX                            ADC1
// 同时修改 DMA 数据流和通道
#define ADC_DMA_ADCX_DMASX                      DMA2_Stream0
#define ADC_DMA_ADCX_DMASX_CHY                  DMA_CHANNEL_0

**现象**：切换到 ADC1，需同步修改 DMA 映射。

**结论**：不同 ADC 的 DMA 映射不同，切换时需查 DMA 映射表。
