# 实验 17：多通道ADC(DMA)

本实验通过 STM32F407ZGT6 的 **ADC1** 和 **DMA2** 配合，实现**多通道（双通道）无需 CPU 干预的连续自动采样**。ADC1 按顺序扫描 PA5（通道 5）和 PA6（通道 6），DMA 自动将数据搬运到内存缓冲区，CPU 仅在数据准备就绪时进行处理。

### ① 时钟树

**目标**：理解多通道 ADC + DMA 模式下的时钟配置。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ STM32F407 时钟树（多通道 ADC + DMA） │
├──────────────────────────────────────────────────────────────────────────────┤
│ │
│ APB2（84MHz）→ ADC1 预分频器（/4）→ 21MHz → ADC1 核心 │
│ AHB（168MHz）→ DMA2 控制器 → DMA2_Stream0 → ADC1 的 DMA 请求 │
│ │
│ 工作流程： │
│ ① ADC1 扫描通道：PA5 → PA6 → PA5 → PA6 ... │
│ ② 每次转换完成 → 触发 DMA 请求 │
│ ③ DMA2_Stream0 自动从 ADC_DR 读取数据 → 存入缓冲区 │
│ ④ 缓冲区数据排列：buf[0]=PA5, buf[1]=PA6, buf[2]=PA5, buf[3]=PA6 ... │
│ │
└──────────────────────────────────────────────────────────────────────────────┘
```

#### 与单通道 DMA 实验的对比

| 对比项         | 单通道 DMA（实验 15） | 多通道 DMA（本实验）                    |
| ----------- | -------------- | ------------------------------- |
| **ADC 外设**  | ADC3           | **ADC1**                        |
| **通道数量**    | 1 个            | **2 个（PA5 + PA6）**              |
| **扫描模式**    | `DISABLE`      | **`ENABLE`**                    |
| **DMA 数据流** | DMA2_Stream1   | **DMA2_Stream0**                |
| **DMA 通道**  | Channel 2      | **Channel 0**                   |
| **缓冲区数据**   | 全是同一通道         | **交错排列（CH5, CH6, CH5, CH6...）** |
| **数据处理**    | 直接取平均          | **分别提取两个通道再取平均**                |

### ② 寄存器级

> **目标**：从寄存器层面理解多通道 ADC + DMA 的配置。

#### ADC 寄存器配置（扫描模式）

| 寄存器          | 位/字段         | 本实验配置           | 说明               |
| ------------ | ------------ | --------------- | ---------------- |
| **ADC_CR1**  | **SCAN**     | **1（启用）**       | 启用扫描模式，按顺序转换多个通道 |
| **ADC_CR2**  | **CONT**     | **1（启用）**       | 连续转换模式，一直运行      |
| **ADC_CR2**  | **DMA**      | **1（启用）**       | 使能 DMA 传输        |
| **ADC_CR2**  | **DDS**      | **1（启用）**       | 每次转换都触发 DMA 请求   |
| **ADC_SQR1** | **L[3:0]**   | **2**           | 规则通道序列长度（2 个通道）  |
| **ADC_SQR3** | **SQ1[4:0]** | `ADC_CHANNEL_5` | 第 1 个转换的通道（PA5）  |
| **ADC_SQR3** | **SQ2[4:0]** | `ADC_CHANNEL_6` | 第 2 个转换的通道（PA6）  |

#### DMA 寄存器

| 寄存器            | 值                      | 说明                           |
| -------------- | ---------------------- | ---------------------------- |
| **DMA_SxCR**   | 外设→内存，16 位，内存递增        | 从 ADC_DR 读取，存入数组             |
| **DMA_SxPAR**  | `&ADC1->DR`            | 外设地址（ADC1 数据寄存器）             |
| **DMA_SxM0AR** | `g_adc_nch_dma_buf`    | 内存地址（缓冲区首地址）                 |
| **DMA_SxNDTR** | `ADC_NCH_DMA_BUF_SIZE` | 传输总数（100 = 每个通道 50 次 × 2 通道） |

#### DMA 映射表（本实验相关）

| 外设请求     | DMA 控制器  | 数据流          | 通道            | 说明           |
| -------- | -------- | ------------ | ------------- | ------------ |
| **ADC1** | **DMA2** | **Stream 0** | **Channel 0** | **本实验使用**    |
| ADC2     | DMA2     | Stream 2 / 3 | Channel 1     | -            |
| ADC3     | DMA2     | Stream 0 / 1 | Channel 2     | 单通道 DMA 实验使用 |

### ③ 数据流

**目标**：理清多通道 ADC + DMA 协同工作的完整数据流。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 多通道 ADC + DMA 完整数据流 │
├─────────────────────────────────────────────────────────────────────────────┤
│ │
│ 【硬件层】（完全自动运行，CPU 不参与） │
│ │
│ PA5 模拟电压 → ADC1 通道 5 │
│ PA6 模拟电压 → ADC1 通道 6 │
│ │ │
│ ▼ │
│ ADC1 扫描转换：PA5 → PA6 → PA5 → PA6 ... │
│ │ │
│ ▼ │
│ 每次转换完成 → 触发 DMA 请求 → DMA2_Stream0_Channel0 │
│ │ │
│ ▼ │
│ DMA 写入缓冲区：buf[0]=PA5, buf[1]=PA6, buf[2]=PA5, buf[3]=PA6 ... │
│ │ │
│ ▼ │
│ 采集完 100 个数据 → DMA 传输完成中断 │
│ │
│ 【中断层】 │
│ │
│ DMA2_Stream0_IRQHandler → HAL_DMA_IRQHandler │
│ │ │
│ ▼ │
│ HAL_ADC_ConvCpltCallback() → g_adc_nch_dma_sta = 1 │
│ │
│ 【应用层】（CPU 在主循环中处理） │
│ │
│ 检测到 sta == 1 → 分别提取两个通道的数据 │
│ │ │
│ ├── CH5：buf[0], buf[2], buf[4]... → 取平均 → 显示 │
│ └── CH6：buf[1], buf[3], buf[5]... → 取平均 → 显示 │
│ │
└─────────────────────────────────────────────────────────────────────────────┘
```

### ④ 中断/DMA 机制

> **目标**：理解多通道 DMA 传输完成中断的触发与处理流程。

#### DMA 中断触发条件

| 事件         | 触发条件           | 处理函数                       | 作用             |
| ---------- | -------------- | -------------------------- | -------------- |
| **传输完成中断** | DMA 搬完 100 个数据 | `HAL_ADC_ConvCpltCallback` | 置位标志，通知主循环处理数据 |

#### 与单通道 DMA 的中断对比

| 对比项        | 单通道 DMA      | 多通道 DMA（本实验）       |
| ---------- | ------------ | ------------------ |
| **缓冲区大小**  | 50           | **100（50 × 2）**    |
| **中断频率**   | 每 50 次采样触发   | **每 100 次采样触发**    |
| **中断时数据量** | 1 个通道 × 50 次 | **2 个通道 × 各 50 次** |
| **CPU 处理** | 直接取平均        | **分别提取再取平均**       |

### ⑤ 改参实验

#### 改参实验 1：修改通道数量

**操作**：在 `adc.h` 中修改 `ADC_NCH_DMA_ADCX_CH_NUM` 宏。

```
// 修改前
#define ADC_NCH_DMA_ADCX_CH_NUM 2
// 修改后（3 通道）
#define ADC_NCH_DMA_ADCX_CH_NUM 3
// 同时新增第 3 个通道的宏定义
#define ADC_NCH_DMA_ADCX_CHC ADC_CHANNEL_7
#define ADC_NCH_DMA_ADCX_CHC_GPIO_PIN GPIO_PIN_7
```

**现象**：可同时采集 3 路模拟信号。

**结论**：多通道 ADC 可灵活扩展，只需修改宏定义和初始化代码。

#### 改参实验 2：修改 DMA 模式

**操作**：在 `HAL_ADC_MspInit` 中修改 DMA 模式。

```
// 修改前（普通模式，每次都要重新启动）
g_adc_nch_dma_dma_handle.Init.Mode = DMA_NORMAL;
// 修改后（循环模式，自动循环覆盖）
g_adc_nch_dma_dma_handle.Init.Mode = DMA_CIRCULAR;
```

**现象**：循环模式下无需重新调用 `adc_nch_dma_enable()`，DMA 自动循环填充缓冲区。

**结论**：循环模式适合**持续不间断采样**，但需注意数据覆盖问题。

#### 改参实验 3：修改每个通道的采样次数

**操作**：在 `main.c` 中修改宏定义。

```
// 修改前
#define ADC_NCH_DMA_BUF_SIZE (50 * ADC_NCH_DMA_ADCX_CH_NUM)
// 修改后（每个通道采样 100 次）
#define ADC_NCH_DMA_BUF_SIZE (100 * ADC_NCH_DMA_ADCX_CH_NUM)
```

**现象**：缓冲区变大，均值滤波结果更稳定，但 DMA 中断频率降低。

**结论**：采样次数越多，数据越稳定，但响应越慢。

#### 改参实验 4：修改扫描顺序

**操作**：在 `adc_nch_dma_enable()` 中调整 `rank` 参数。

```
// 当前：PA5 先转，PA6 后转
adc_channel_set(..., ADC_NCH_DMA_ADCX_CHA, 1, ...);
adc_channel_set(..., ADC_NCH_DMA_ADCX_CHB, 2, ...);
// 修改后：PA6 先转，PA5 后转
adc_channel_set(..., ADC_NCH_DMA_ADCX_CHB, 1, ...);
adc_channel_set(..., ADC_NCH_DMA_ADCX_CHA, 2, ...);
```

**现象**：缓冲区数据排列变为 `buf[0]=PA6, buf[1]=PA5, buf[2]=PA6, buf[3]=PA5...`

**结论**：`rank` 决定转换顺序，修改 `rank` 可调整扫描优先
