### ② 寄存器级

> **目标**：从寄存器层面理解输入捕获的工作原理。

#### 输入捕获相关寄存器

| 寄存器            | 作用           | 本实验配置                      |
| -------------- | ------------ | -------------------------- |
| **TIM5_PSC**   | 预分频寄存器       | 84 - 1 = 83（计数时钟 1MHz）     |
| **TIM5_ARR**   | 自动重装载寄存器     | 0xFFFF（最大计数范围）             |
| **TIM5_CCR1**  | 捕获/比较寄存器 1   | 捕获到边沿时硬件自动锁存 CNT 值         |
| **TIM5_CCMR1** | 捕获/比较模式寄存器 1 | 配置为输入捕获模式（CC1S = 01）       |
| **TIM5_CCER**  | 捕获/比较使能寄存器   | CC1E = 1，CC1P 控制极性（上升/下降沿） |
| **TIM5_SR**    | 状态寄存器        | CC1IF（捕获中断标志）、UIF（更新中断标志）  |
| **TIM5_CNT**   | 计数器寄存器       | 实时计数值，边沿到来时硬件锁存到 CCR       |

#### GPIO 复用功能配置（PA0 → TIM5_CH1）

// 1. 使能 GPIOA 时钟
RCC->AHB1ENR |= (1 << 0);     // GPIOAEN
// 2. 配置 PA0 为复用功能模式
GPIOA->MODER &= ~(3 << 0);     // 清除 bit1:0
GPIOA->MODER |= (2 << 0);      // 10 = 复用功能模式
// 3. 配置 PA0 的复用功能为 AF2（TIM5）
GPIOA->AFR[0] &= ~(0xF << 0);  // 清除 AFR0 bit3:0
GPIOA->AFR[0] |= (2 << 0);     // AF2 = TIM5

### ④ 中断/DMA 机制

> **目标**：理解输入捕获的中断协作机制。

#### 本实验的中断方案：双中断协作

| 中断类型     | 中断标志  | 回调函数                            | 触发时机                  | 职责             |
| -------- | ----- | ------------------------------- | --------------------- | -------------- |
| **捕获中断** | CC1IF | `HAL_TIM_IC_CaptureCallback`    | 上升沿或下降沿到来时            | 启动/停止计时，读取 CCR |
| **更新中断** | UIF   | `HAL_TIM_PeriodElapsedCallback` | 计数器溢出（CNT = ARR → 0）时 | 累加溢出次数，扩展测量范围  |

#### 中断执行顺序（同时发生时）

硬件中断触发
    │
    ▼
进入 TIM5_IRQHandler
    │
    ▼
HAL_TIM_IRQHandler 内部：
    │
    ├── ① 先检查捕获标志（CC1IF）
    │   └── 如果置位 → 调用 HAL_TIM_IC_CaptureCallback
    │
    └── ② 再检查更新标志（UIF）
        └── 如果置位 → 调用 HAL_TIM_PeriodElapsedCallback

> **注意**：两个回调函数在同一个中断服务函数中**按顺序执行**，不会并行运行。如果捕获事件和溢出事件同时发生，先执行捕获回调，后执行溢出回调。

#### `g_timx_chy_cap_sta` 状态变量详解

这是一个 8 位状态变量，各位含义如下：

| 位          | 掩码     | 含义       | 操作                |
| ---------- | ------ | -------- | ----------------- |
| **bit7**   | `0x80` | 捕获完成标志   | 1 = 测量完成，等待主循环读取  |
| **bit6**   | `0x40` | 已捕获上升沿标志 | 1 = 已捕获到上升沿，正在计时中 |
| **bit5~0** | `0x3F` | 溢出次数计数器  | 记录定时器溢出的次数（最大 63） |

**状态流转图**：

空闲状态        按下按键（上升沿）        正在计时        松开按键（下降沿）      完成状态
(bit6=0)  ──────────────────────────▶ (bit6=1)  ──────────────────────────▶ (bit7=1)
                   │                               │
                   │                               │
                   ▼                               ▼
             计数器归零                    读取 CCR
             改为下降沿触发                 改为上升沿触发
                                           bit7 = 1

正在计时期间（bit6=1）：
    如果计数器溢出 → HAL_TIM_PeriodElapsedCallback → sta++（溢出次数+1）
    如果溢出次数达到 63 → 强制标记完成（sta |= 0x80, cap_val = 0xFFFF）

#### 中断与轮询的对比

| 方案       | 优点        | 缺点            | 本实验   |
| -------- | --------- | ------------- | ----- |
| **中断捕获** | 实时性高，不漏边沿 | 代码复杂度较高       | ✅ 使用  |
| **轮询读取** | 代码简单      | 可能漏边沿，CPU 占用高 | ❌ 未使用 |



### ⑤ 改参实验

> **目标**：通过修改参数验证对输入捕获的理解。

#### 改参实验 1：修改计数时钟（改变分辨率）

**操作**：将 `gtim_timx_cap_chy_init(0xFFFF, 84 - 1)` 改为 `gtim_timx_cap_chy_init(0xFFFF, 168 - 1)`。

**计算**：PSC = 167 → 计数时钟 = 84MHz / 168 = 0.5MHz → 每个计数脉冲 = 2μs。

**现象**：分辨率降低一半（从 1μs 变为 2μs），但最大可测时间翻倍（130ms × 63 ≈ 8.2 秒）。

**结论**：分辨率与最大测量范围是**相互制约**的，需要根据实际需求权衡。

#### 改参实验 2：修改 ARR 值（改变单次最大测量范围）

**操作**：将 `gtim_timx_cap_chy_init(0xFFFF, 84 - 1)` 改为 `gtim_timx_cap_chy_init(10000 - 1, 84 - 1)`。

**计算**：ARR = 9999 → 单次最大测量 = 10000μs = 10ms。

**现象**：测量范围缩小到 10ms，超过 10ms 的信号会产生多次溢出，但由于溢出计数器只有 6 位（最大 63），总测量范围变为 10ms × 63 ≈ 630ms。

**结论**：`ARR` 决定单次测量窗口，`ARR` 越大，单次可测时间越长，但溢出计数器分辨率降低。

#### 改参实验 3：修改测量对象（测低电平时间）

**操作**：将初始触发极性从 `TIM_ICPOLARITY_RISING` 改为 `TIM_ICPOLARITY_FALLING`。

**现象**：测量的是**低电平**持续时间，而不是高电平。

**结论**：通过修改极性，可以灵活测量高电平或低电平的持续时间。

#### 改参实验 4：双边沿触发

**操作**：将捕获极性改为 `TIM_ICPOLARITY_BOTHEDGE`，取消动态切换极性的逻辑。

**现象**：按下和松开都会触发同一个中断，需要在中断中读取引脚电平来判断是上升沿还是下降沿。

**结论**：双边沿触发简化了配置，但增加了软件判断的复杂度。

#### 改参实验 5：修改溢出计数器上限

**操作**：将 `if ((g_timx_chy_cap_sta & 0x3F) == 0x3F)` 改为 `0x1F`（上限从 63 改为 31）。

**现象**：最大测量范围减半（约 2 秒），超过后强制结束测量。

**结论**：溢出计数器上限决定了最大可测时间，可以根据需求调整。

#### 改参实验 6：按键消抖对测量结果的影响

**操作**：在按键电路上并联一个 0.1μF 电容，观察测量结果的变化。

**现象**：测量结果更加稳定，不会因为按键抖动而产生异常值。

**结论**：硬件消抖可以滤除按键按下/松开瞬间的抖动，使测量结果更准确。

### 踩坑记录

> **目标**：记录调试过程中遇到的实际问题及解决方法。

| 序号  | 问题现象                    | 原因分析                                                         | 解决方法                                    |
| --- | ----------------------- | ------------------------------------------------------------ | --------------------------------------- |
| 1   | **按键按下后无输出**            | PA0 未正确配置为复用功能                                               | 检查 `GPIO_AF2_TIM5` 是否正确配置               |
| 2   | **测量结果始终为 0**           | 按键电路未接下拉电阻，PA0 悬空                                            | 在 PA0 和 GND 之间接 10kΩ 下拉电阻               |
| 3   | **测量结果偏大或偏小**           | 计数时钟计算错误（未考虑 APB1 倍频）                                        | TIM5 时钟 = 84MHz，不是 42MHz                |
| 4   | **重复打印多次结果**            | 主循环未清除 `g_timx_chy_cap_sta`                                  | 打印后执行 `g_timx_chy_cap_sta = 0`          |
| 5   | **长按按键（>4秒）后测量结果异常**    | 溢出计数器达到最大值 63，被强制结束                                          | 属于正常保护机制，可增大溢出计数器位数或修改 ARR              |
| 6   | **按下按键后一直无输出，直到松开才打印**  | 正常现象（上升沿开始计时，下降沿才完成）                                         | 这是输入捕获的设计逻辑，不是 Bug                      |
| 7   | **串口打印数值跳动**            | 按键抖动导致多次触发                                                   | 硬件加电容滤波，或软件增加消抖判断                       |
| 8   | **TIM5_IRQHandler 未执行** | NVIC 中断未使能                                                   | 检查 `HAL_NVIC_EnableIRQ(TIM5_IRQn)` 是否调用 |
| 9   | **溢出回调未执行**             | `__HAL_TIM_ENABLE_IT(&g_timx_cap_handle, TIM_IT_UPDATE)` 未调用 | 确保在初始化中使能了更新中断                          |
| 10  | **PA0 复用功能与按键冲突**       | PA0 同时也是 WKUP 按键                                             | 确保 WKUP 按键未占用 PA0，或断开连接                 |
