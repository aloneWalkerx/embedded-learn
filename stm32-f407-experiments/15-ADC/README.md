# 实验 15：单通道ADC

本实验通过 STM32F407ZGT6 的 **ADC2（模数转换器）** 和 **通道 1（PA1）**，将外部模拟电压信号（如电位器分压）转换为 12 位数字量，并在 LCD 上实时显示原始值和换算后的电压值。

### ① 时钟树

> **目标**：理解 ADC 外设的时钟来源、分频路径与配置。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ STM32F407 时钟树（ADC 模数转换部分） │
├──────────────────────────────────────────────────────────────────────────────┤
│ │
│ 【ADC 时钟路径】 │
│ │
│ ┌──────────────────────────────────────────────────────────────────────┐ │
│ │ PLL 锁相环 │ │
│ │ 8MHz / 8 × 336 / 2 = 168MHz │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│ │ │
│ ▼ │
│ ┌──────────────────────────────────────────────────────────────────────┐ │
│ │ AHB 分频 HPRE=1 → HCLK = 168MHz │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│ │ │
│ ▼ │
│ ┌──────────────────────────────────────────────────────────────────────┐ │
│ │ APB2 分频 PPRE2=2 → PCLK2 = 84MHz │ │
│ │ ADC1/2/3 挂载在 APB2 上 │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│ │ │
│ ▼ │
│ ┌──────────────────────────────────────────────────────────────────────┐ │
│ │ ADC 预分频器 │ │
│ │ ADC_CLOCK_SYNC_PCLK_DIV4 → 84MHz / 4 = 21MHz │ │
│ │ ★ ADC 最大允许频率为 30MHz，21MHz 是安全且常用的值 │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│ │ │
│ ▼ │
│ ┌──────────────────────────────────────────────────────────────────────┐ │
│ │ ADC 核心（逐次逼近型） │ │
│ │ 采样时间（480 周期）+ 转换时间（12 周期） │ │
│ │ ★ 总转换时间 ≈ 492 / 21MHz ≈ 23.4µs │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│ │
├──────────────────────────────────────────────────────────────────────────────┤
│ 关键配置： │
│ ┌─────────────────────┬────────────────────────────────────────────────┐ │
│ │ ADC 时钟源 │ APB2（84MHz） │ │
│ │ ADC 预分频 │ 4 分频 → 21MHz │ │
│ │ 分辨率 │ 12 位（0~4095） │ │
│ │ 采样时间 │ 480 周期（精度最高） │ │
│ │ 转换时间 │ 12 周期（固定） │ │
│ │ 总转换时间 │ 492 / 21MHz ≈ 23.4µs │ │
│ └─────────────────────┴────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────┘
```

#### 与前面实验的时钟对比

| 实验             | 核心外设     | 主要时钟源           | 用途             |
| -------------- | -------- | --------------- | -------------- |
| 实验 9（TFTLCD）   | FSMC     | APB1（42MHz）     | 驱动 8080 接口彩屏   |
| 实验 11（RTC）     | RTC      | LSE（32.768kHz）  | 实时时钟/日历/闹钟     |
| 实验 13（DMA）     | DMA2     | AHB（168MHz）     | 高速数据搬运         |
| **实验 14（ADC）** | **ADC2** | **APB2（21MHz）** | **模拟电压 → 数字量** |

> **核心特点**：ADC 的转换速度取决于 APB2 时钟和预分频系数，21MHz 下单次转换约 **23.4µs**，每秒可采集约 **4.2 万次**。

### ② 寄存器级

#### ADC 转换原理（逐次逼近）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 逐次逼近型 ADC 工作原理（12 位） │
├──────────────────────────────────────────────────────────────────────────────┤
│ │
│ 外部模拟电压（如 1.65V）→ PA1 → 采样保持电容 → 比较器 │
│ │
│ 逐次逼近过程（二分查找）： │
│ │
│ ① 第 1 次比较：VIN（1.65V）与 VREF/2（1.65V）比较 → 相等 → bit11 = 1 │
│ ② 第 2 次比较：VIN 与 3VREF/4（2.475V）比较 → 小于 → bit10 = 0 │
│ ③ 第 3 次比较：VIN 与 5VREF/8（2.0625V）比较 → 小于 → bit9 = 0 │
│ ④ ...（重复 12 次） │
│ ? 第 12 次比较：得出 bit0 │
│ │
│ 最终结果：2048（对应 1.65V） │
│ │
│ ★ 12 位分辨率 → 12 次比较 → 结果范围 0~4095 │
│ ★ 最小分辨电压：3.3V / 4096 ≈ 0.8mV │
│ │
└──────────────────────────────────────────────────────────────────────────────┘
```

### ③ 数据流

> **目标**：理清从“外部模拟电压”到“LCD 显示数字值”的完整链路。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ADC 完整数据流（电压 → 数字 → 显示） │
├──────────────────────────────────────────────────────────────────────────────┤
│ │
│ 【硬件层】（外部信号） │
│ │
│ 电位器分压（0~3.3V）→ PA1（ADC2 通道 1） │
│ │
│ 【ADC 硬件层】（自动完成） │
│ │
│ ① 采样保持电容充电（480 周期） │
│ ② 逐次逼近比较（12 周期） │
│ ③ 结果存入 ADC_DR 寄存器 │
│ ④ EOC 标志置位 │
│ │
│ 【HAL 库层】（轮询等待） │
│ │
│ HAL_ADC_Start() → 启动转换 │
│ HAL_ADC_PollForConversion() → 等待 EOC 标志 │
│ HAL_ADC_GetValue() → 读取 ADC_DR 寄存器 │
│ │
│ 【应用层】（数据加工） │
│ │
│ ① adc_get_result() → 返回 12 位原始值（0~4095） │
│ ② adc_get_result_average() → 采样 10 次取平均值（软件滤波） │
│ ③ voltage = (adc_result × 3300) / 4095 → 换算为毫伏值 │
│ ④ lcd_show_xnum() → 显示 ADC 值 + 电压值 │
│ │
│ 【LCD 显示层】 │
│ │
│ ADC2_CH1_VAL: 2048 │
│ ADC2_CH1_VOL: 1.650V │
│ │
└──────────────────────────────────────────────────────────────────────────────┘
```

### ④ 中断/DMA 机制

> **目标**：理解本实验的 ADC 采集方式。

#### 本实验的方案：**无中断，无 DMA，纯轮询**

| 机制      | 是否使用 | 说明                                      |
| ------- | ---- | --------------------------------------- |
| **中断**  | 否    | 使用 `HAL_ADC_PollForConversion` 轮询等待转换完成 |
| **DMA** | 否    | 未使用 DMA，每次由 CPU 主动触发并读取                 |

#### 与其他实验的对比

| 实验             | 数据采集方式      | CPU 占用率       | 适用场景          |
| -------------- | ----------- | ------------- | ------------- |
| 实验 7（输入捕获）     | 中断          | 中             | 信号测量          |
| 实验 13（DMA）     | DMA 后台搬运    | 极低            | 大数据量传输        |
| **实验 14（ADC）** | **轮询（本实验）** | **高（等待期间卡住）** | **学习/简单采集**   |
| ADC + DMA（进阶）  | DMA 连续采样    | 极低            | 高速连续采样（音频/电机） |

> **为什么不用 DMA？**  
> 本实验为学习目的，使用最简单的轮询方式，让初学者清楚看到 ADC 转换的每一步。实际项目中建议使用 **ADC + DMA + 连续转换模式**，实现 CPU 零参与的高速采样。

### ⑤ 改参实验

> **目标**：通过修改参数验证对 ADC 功能的理解。

#### 改参实验 1：修改采样时间

**操作**：在 `adc_channel_set()` 中修改 `sampling_time` 参数。

```
// 修改前（精度最高）
adc_channel_set(&g_adc_handle, channel, 1, ADC_SAMPLETIME_480CYCLES);
// 修改后（速度最快）
adc_channel_set(&g_adc_handle, channel, 1, ADC_SAMPLETIME_3CYCLES);
```

**现象**：采样时间越短，转换速度越快，但精度可能下降（尤其是高阻抗信号源）。

**结论**：采样时间需根据**信号源内阻**选择——内阻小用短采样时间，内阻大用长采样时间。

---

#### 改参实验 2：修改分辨率

**操作**：在 `adc_init()` 中修改 `Resolution` 参数。

```
// 修改前（12 位）
g_adc_handle.Init.Resolution = ADC_RESOLUTION_12B;
// 修改后（10 位）
g_adc_handle.Init.Resolution = ADC_RESOLUTION_10B;
```

**现象**：分辨率降低，最大 ADC 值从 4095 变为 1023，精度下降但转换速度略快。

**结论**：分辨率与速度是**权衡关系**，高精度应用用 12 位，高速应用可降低分辨率。

---

#### 改参实验 3：修改均值滤波次数

**操作**：在 `adc_get_result_average()` 中修改 `times` 参数。

```
// 修改前（10 次）
adc_result = adc_get_result_average(ADC_ADCX_CHY, 10);
// 修改后（50 次）
adc_result = adc_get_result_average(ADC_ADCX_CHY, 50);
```

**现象**：次数越多，结果越稳定，但采样速度越慢（50 次 × 23.4µs ≈ 1.17ms）。

**结论**：滤波次数是**稳定性与速度的权衡**，稳定信号用 5~10 次，干扰大的信号用 20~50 次。

---

#### 改参实验 4：修改 ADC 通道

**操作**：在 `adc.h` 中修改通道和引脚宏定义。

```
// 修改前（PA1）
#define ADC_ADCX_CHY ADC_CHANNEL_1
#define ADC_ADCX_CHY_GPIO_PIN GPIO_PIN_1
// 修改后（PA0）
#define ADC_ADCX_CHY ADC_CHANNEL_0
#define ADC_ADCX_CHY_GPIO_PIN GPIO_PIN_0
```



**现象**：ADC 采样引脚从 PA1 切换到 PA0。

**结论**：修改引脚只需改宏定义，代码主体无需改动，移植非常方便。

---

#### 改参实验 5：外部输入悬空时观察跳动

**操作**：不接任何外部信号源，让 PA1 悬空。

**现象**：ADC 值在 0~4095 之间随机跳动，显示电压不稳。

**结论**：模拟输入引脚**不能悬空**，必须接到确定的电压源（GND、3.3V、电位器或传感器）。
