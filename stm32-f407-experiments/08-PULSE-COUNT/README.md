# 实验 8：脉冲计数

本实验通过STM32F407ZGT6板载的TIM2通用定时器以及复用PA0引脚作为通道1捕获脉冲计数（====底部有实验结果====）

#### 与前面实验的时钟对比

| 实验             | 定时器      | 时钟来源       | 用途         |
| -------------- | -------- | ---------- | ---------- |

### ② 寄存器级

> **目标**：从寄存器层面理解脉冲计数的工作原理。

#### 脉冲计数相关寄存器

| 寄存器            | 作用           | 本实验配置                                     |
| -------------- | ------------ | ----------------------------------------- |
| **TIM2_SMCR**  | 从模式控制寄存器     | 配置为外部时钟模式 1（SMS=111），触发源选择 TI1FP1（TS=101） |
| **TIM2_CCER**  | 捕获/比较使能寄存器   | CC1P 配置极性（上升/下降沿）                         |
| **TIM2_CCMR1** | 捕获/比较模式寄存器 1 | 配置为输入捕获模式（CC1S=01）                        |
| **TIM2_PSC**   | 预分频寄存器       | 本实验设为 0（不分频）                              |
| **TIM2_ARR**   | 自动重装载寄存器     | 0xFFFF（最大计数值）                             |
| **TIM2_CNT**   | 计数器寄存器       | 实时脉冲计数值（每来一个脉冲自动 +1）                      |
| **TIM2_SR**    | 状态寄存器        | UIF（更新中断标志，溢出时置位）                         |

#### 从模式配置详解

脉冲计数的核心是 **从模式（Slave Mode）**，它让定时器不再依赖内部时钟，而是由外部信号驱动。

| 配置项            | 寄存器位             | 本实验值            | 含义              |
| -------------- | ---------------- | --------------- | --------------- |
| **SMS**（从模式选择） | TIM2_SMCR bit2:0 | `111`（外部时钟模式 1） | 计数器的时钟由外部触发信号提供 |
| **TS**（触发源选择）  | TIM2_SMCR bit6:4 | `101`（TI1FP1）   | 触发源为通道 1 的输入信号  |
| **CC1P**（捕获极性） | TIM2_CCER bit1   | `0`（上升沿）        | 上升沿触发计数         |

### ④ 中断/DMA 机制

> **目标**：理解脉冲计数的中断机制。

#### 本实验的中断方案：仅溢出中断

| 中断类型         | 触发条件               | 回调函数                            | 作用                   |
| ------------ | ------------------ | ------------------------------- | -------------------- |
| **更新中断（溢出）** | CNT 从 0xFFFF 溢出到 0 | `HAL_TIM_PeriodElapsedCallback` | 溢出次数 +1，扩展计数范围到 32 位 |

#### 与输入捕获的中断对比

| 维度          | 输入捕获（实验 7）  | 脉冲计数（本实验）                 |
| ----------- | ----------- | ------------------------- |
| **中断类型**    | 捕获中断 + 溢出中断 | **仅溢出中断**                 |
| **中断触发频率**  | 每个边沿触发一次    | 仅溢出时触发（约 65535 个脉冲触发一次）   |
| **CPU 占用率** | 较高（每个脉冲都中断） | **极低**（平均 65535 个脉冲才中断一次） |
| **数据读取方式**  | 中断中读取 CCR   | 主循环轮询读取 CNT               |

#### 为什么脉冲计数更高效？

输入捕获**每个边沿**都要触发中断，CPU 需要处理每个脉冲；而脉冲计数的计数过程**完全由硬件完成**，只有溢出时才触发中断。

对于高频脉冲信号（如几十 kHz），脉冲计数方式可以大幅降低 CPU 的负载。

#### 总计数公式

text

总脉冲数 = 溢出次数 × 65535 + 当前 CNT 值

其中：

- 溢出次数：`g_timx_chy_cnt_ofcnt`（uint32_t，最大约 42 亿）

- 当前 CNT：`__HAL_TIM_GET_COUNTER()`（0~65535）

- 总计数范围：0 ~ 约 281,474,976,710,655（约 281 万亿）



### ⑤ 改参实验

> **目标**：通过修改参数验证对脉冲计数的理解。

#### 改参实验 1：修改触发极性（改为下降沿计数）

**操作**：将 `TriggerPolarity` 从 `TIM_TRIGGERPOLARITY_RISING` 改为 `TIM_TRIGGERPOLARITY_FALLING`。

c

tim_slave_config_struct.TriggerPolarity = TIM_TRIGGERPOLARITY_FALLING;

**现象**：计数器在信号**下降沿**时 +1，而不是上升沿。

**结论**：可以灵活选择上升沿或下降沿计数，适应不同信号源的输出极性。

#### 改参实验 2：修改预分频器（实现脉冲分频）

**操作**：将 `gtim_timx_cnt_chy_init(0)` 改为 `gtim_timx_cnt_chy_init(4 - 1)`。

**现象**：每 4 个脉冲计数器才 +1，相当于实现了 4 分频。

**公式**：实际计数频率 = 输入脉冲频率 / (PSC + 1)

**结论**：预分频器可以对输入脉冲进行分频，适用于高频信号计数。

#### 改参实验 3：修改自动重装载值（改变单次计数范围）

**操作**：将 `g_timx_cnt_handle.Init.Period = 0xFFFF` 改为 `1000 - 1`。

**现象**：计数器计数到 999 后溢出，溢出周期从 65535 变为 1000。

**结论**：`ARR` 决定单次计数窗口大小，减小 ARR 可以降低溢出周期，适合低频信号。

#### 改参实验 4：用 PWM 信号作为脉冲源

**操作**：将 PWM 实验的 PB4（TIM3_CH1）输出连接到 PA0（TIM2_CH1），然后改变 PWM 的频率。

**现象**：串口打印的脉冲计数速度随 PWM 频率变化。

**结论**：脉冲计数可以用于测量任意方波信号的脉冲个数。

#### 改参实验 5：按键手动产生脉冲

**操作**：在 PA0 和 3.3V 之间接一个按键，每按一次产生一个上升沿。

**现象**：每按一次按键，串口打印的计数值 +1。

**结论**：任何产生上升沿或下降沿的信号源都可以作为脉冲计数器的输入。
