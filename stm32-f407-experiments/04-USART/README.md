**波特率计算公式（以 USART1 为例）**：

text

USARTDIV = PCLK2 / (8 × (2 - OVER8) × 波特率)
当 OVER8=0（16倍过采样）：
USARTDIV = 84,000,000 / (16 × 115200) ≈ 45.572
小数部分 0.572 × 16 = 9.15 ≈ 9
所以：DIV_Mantissa = 45，DIV_Fraction = 9
BRR 寄存器值 = (45 << 4) | 9 = 729



### ② 寄存器级

> **目标**：从寄存器层面理解 USART 的配置与数据收发过程。

#### USART 核心寄存器

| 寄存器           | 作用                     | 本实验配置                     |
| ------------- | ---------------------- | ------------------------- |
| **USART_CR1** | 控制寄存器 1（使能、收发、数据位、校验）  | UE=1, TE=1, RE=1, M=0（8位） |
| **USART_CR2** | 控制寄存器 2（停止位）           | STOP=0（1位停止位）             |
| **USART_BRR** | 波特率寄存器                 | 根据 84MHz 和 115200 计算写入    |
| **USART_SR**  | 状态寄存器（TXE、TC、RXNE 等标志） | 轮询等待标志位                   |
| **USART_DR**  | 数据寄存器（收发共用）            | 写入=发送，读取=接收               |

#### 关键标志位（`USART_SR` 寄存器）

| 位    | 标志位  | 含义               | 本实验使用          |
| ---- | ---- | ---------------- | -------------- |
| bit5 | RXNE | 接收数据寄存器非空（已收到数据） | 中断接收           |
| bit6 | TC   | 发送完成（数据已完全发出）    | `printf` 等待此标志 |
| bit7 | TXE  | 发送数据寄存器为空（可发新数据） | 非阻塞发送          |

### ④ 中断/DMA 机制

> **目标**：理解串口中断和 DMA 的工作机制及其应用场景。

#### 本实验方案：中断接收 + 轮询发送

| 方向         | 方式                                 | 说明                |
| ---------- | ---------------------------------- | ----------------- |
| **发送（TX）** | 轮询（`printf` / `HAL_UART_Transmit`） | CPU 主动发送，等待 TC 标志 |
| **接收（RX）** | 中断（`HAL_UART_Receive_IT`）          | 硬件收到数据后触发中断通知 CPU |

#### 接收中断详细流程

text

电脑发送 1 个字节到 RX 引脚
    │
    ▼
硬件自动存入 USART_DR 寄存器
    │
    ▼
RXNE 标志位置 1 → 触发中断请求
    │
    ▼
NVIC 收到中断请求 → 跳转到 USART1_IRQHandler
    │
    ▼
HAL_UART_IRQHandler(&g_uart_i_handle)
    │
    ▼
HAL_UART_RxCpltCallback() 被调用
    │
    ├── g_usart_i_rx_buffer[0] = 收到的 1 个字节
    ├── 判断是 \r（0x0D）→ 标记 bit14
    ├── 判断是 \n（0x0A）→ 标记 bit15（接收完成）
    └── 普通字符 → 存入 g_usart_i_rx_buf[]，长度+1
    │
    ▼
重新开启下一次中断接收
HAL_UART_Receive_IT(&g_uart_i_handle, g_usart_i_rx_buffer, 1);

#### `g_usart_i_rx_status_data` 状态变量详解

这是一个 16 位变量，用不同的位记录不同的信息：

| 位                | 掩码       | 含义                                 |
| ---------------- | -------- | ---------------------------------- |
| **bit15**        | `0x8000` | **接收完成标志**（1 = 已收到 `\r\n`，0 = 接收中） |
| **bit14**        | `0x4000` | **已收到 `\r` 标志**（1 = 已收到回车，0 = 未收到） |
| **bit13 ~ bit0** | `0x3FFF` | **已接收的有效字节数**（最大 16383 字节）         |

#### 扩展方案对比

| 方案              | 实现方式              | 优点             | 缺点            |
| --------------- | ----------------- | -------------- | ------------- |
| **轮询（本实验发送）**   | 主动循环等待标志位         | 简单直观，代码易懂      | 阻塞 CPU        |
| **中断接收（本实验接收）** | RXNE 中断触发，CPU 去处理 | 不阻塞 CPU，实时性好   | 需要管理中断优先级和缓冲区 |
| **DMA 传输**      | DMA 自动搬运数据        | CPU 完全不参与，效率最高 | 配置稍复杂         |



### ⑤ 改参实验

> **目标**：通过修改参数验证对串口的理解。

#### 改参实验 1：修改波特率

**操作**：将 `usart_i_init(115200)` 改为 `usart_i_init(9600)`，同时串口助手也改为 9600。

**现象**：通信正常。

**结论**：通信双方的波特率必须一致。

#### 改参实验 2：修改 `printf` 输出的内容

**操作**：将 `printf("\r\n正点原子 M144Z-M4...")` 改为 `printf("\r\n我的串口实验成功！\r\n")`。

**现象**：串口助手显示修改后的内容。

**结论**：`printf` 的内容由单片机主动发送，由电脑被动显示。

#### 改参实验 3：不勾选“发送新行”

**操作**：在串口助手中取消勾选“发送新行”，手动输入 `123` 发送。

**现象**：单片机没有回显。

**原因**：代码以 `\r\n` 作为帧结束标志，不加 `\r\n` 则单片机永远等不到结束标志，`bit15` 不会置 1。

**结论**：串口通信协议必须双方一致。

#### 改参实验 4：中断回调中修改状态判断

**操作**：将 `if (g_usart_i_rx_buffer[0] == 0x0A)` 改为 `if (g_usart_i_rx_buffer[0] == 0x0D)`。

**现象**：单片机在收到第一个 `\r` 时就标记接收完成，后续数据丢失或错乱。

**结论**：协议状态机的判断条件必须严格匹配约定格式。

### 踩坑记录

> **目标**：记录调试过程中遇到的实际问题及解决方法。

| 序号  | 问题现象              | 原因分析                          | 解决方法                                                 |
| --- | ----------------- | ----------------------------- | ---------------------------------------------------- |
| 1   | **串口助手无任何输出**     | USART 时钟未使能，或 `printf` 未重定向   | 检查 `__HAL_RCC_USART1_CLK_ENABLE()`，检查 `fputc` 是否正确实现 |
| 2   | **输出全是乱码**        | 波特率不匹配（晶振 `HSE_VALUE` 与实际不一致） | 确认外部晶振是 8MHz 还是 25MHz，修改 `HSE_VALUE` 宏               |
| 3   | **发送 `123` 后无回显** | 未正确添加 `\r\n`（回车换行）            | 串口助手发送时勾选“发送新行”或手动加回车                                |
| 4   | **看不到发送的内容**      | 本地回显被关闭                       | 检查串口助手设置，开启本地回显即可                                    |
| 5   | **回显是 `?` 或乱码**   | 波特率偏移或缓冲区数据错误                 | 检查 `HSE_VALUE` 晶振频率，检查回显用的缓冲区是否正确                    |
| 6   | **发送引脚和接收引脚定义错误** | RX 引脚错误配置为 PA9（与 TX 冲突）       | RX 应为 `GPIO_PIN_10`，TX 应为 `GPIO_PIN_9`               |
| 7   | **中断只能收到 1 个字节**  | 回调结束后未重新开启中断接收                | 在回调末尾调用 `HAL_UART_Receive_IT`                        |
