### ② 寄存器级

> **目标**：从寄存器层面理解 PWM 输出的配置与工作原理。

#### TIM3 核心寄存器（PWM 输出）

| 寄存器            | 作用              | 本实验配置                          |
| -------------- | --------------- | ------------------------------ |
| **TIM3_PSC**   | 预分频寄存器          | 84 - 1 = 83（分频系数 84）           |
| **TIM3_ARR**   | 自动重装载寄存器        | 500 - 1 = 499（周期 500μs）        |
| **TIM3_CCR1**  | 捕获/比较寄存器 1（通道1） | 由 `__HAL_TIM_SET_COMPARE` 动态修改 |
| **TIM3_CCMR1** | 捕获/比较模式寄存器 1    | 配置为 PWM 模式 1（OC1M = 110）       |
| **TIM3_CCER**  | 捕获/比较使能寄存器      | CC1E = 1（使能通道1输出）              |
| **TIM3_CR1**   | 控制寄存器 1         | CEN = 1（使能计数器）                 |

PWM 输出的核心是**计数器（CNT）** 和**比较器（CCR）** 的配合：

> **目标**：理清从软件计算占空比到硬件输出 PWM 波形的完整链路。

│                    PWM 输出完整数据流（软件 → 硬件）                         │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【软件层】                                                                  │
│                                                                              │

│       │                                                                      │

│       │   → 宏展开：TIM3->CCR1 = compare                                    │
│       │                                                                      │
│       └── ③ 软件延时                                                        │

│                                                                              │
│  【硬件层（独立运行，无需 CPU 干预）】                                       │
│                                                                              │
│  TIM3 计数器（CNT）从 0 到 499 循环递增                                    │
│       │                                                                      │
│       ├── 硬件比较器持续比较：CNT 与 CCR1                                   │
│       │                                                                      │
│       ├── 当 CNT < CCR1 时                                                  │
│       │   → TIM3_CH1 引脚输出 高电平（3.3V）                                │
│       │                                                                      │
│       └── 当 CNT ≥ CCR1 时                                                  │
│           → TIM3_CH1 引脚输出 低电平（0V）                                  │
│                                                                              │
│  每 500μs 自动重复一次（2kHz 方波）                                        │
│                                                                              │

│                                                                              │
│  【占空比变化过程】                                                          │
│                                                                              │
│  CCR = 0    → 占空比 0%   → PB4 一直低电平（LED 完全熄灭）                 │

### ④ 中断/DMA 机制

> **目标**：理解 PWM 输出与中断的关系。

#### 本实验方案：PWM 输出（无需中断）

PWM 输出**不需要中断**。波形生成由硬件完全独立完成：

- 定时器计数器（CNT）自动计数。

- 比较器自动比较 CNT 和 CCR。

- 引脚电平自动翻转。

**全程不需要 CPU 参与**，这是 PWM 最大的优势——在输出波形的同时，CPU 可以处理其他任务。
