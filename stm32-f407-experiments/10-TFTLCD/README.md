# 实验 10：TFT LCD(MCU屏)

本实验通过 STM32F407ZGT6 的 FSMC 外设（Flexible Static Memory Controller），利用 8080 并行接口 驱动 2.8 寸 TFTLCD 彩屏（驱动芯片 ST7789），实现彩色文字、图形、数字、中文及 BMP 图片的显示功能。显示原理基于 FSMC 将 LCD 当作 SRAM 来操作，通过向特定内存地址写入数据即可完成屏幕刷新（====底部有实验结果====）。

② 寄存器级
目标：从寄存器层面理解 FSMC 驱动 TFTLCD 的工作原理。

FSMC 相关寄存器（Bank1 / NE4）
寄存器	作用	本实验配置
FSMC_BCR4	控制寄存器 4	使能 Bank1 子 Bank4，配置为 SRAM 模式，16 位数据宽度
FSMC_BTR4	时序寄存器 4	配置读操作的地址/数据建立时间（AddressSetupTime=15, DataSetupTime=60）
FSMC_BWTR4	写时序寄存器 4	配置写操作的地址/数据建立时间（AddressSetupTime=3, DataSetupTime=3）
FSMC_Bank1E	扩展模式寄存器	启用读/写分离时序（ExtendedMode = ENABLE）
TFTLCD 内部寄存器（以 ST7789 为例）
寄存器	作用	说明
0x36	扫描方向控制	设置 RGB/BGR、行列镜像
0x3A	像素格式设置	本实验设为 0x05（16 位色，RGB565）
0x2A	列地址设置 (X)	设置显示窗口的 X 起始/结束地址
0x2B	行地址设置 (Y)	设置显示窗口的 Y 起始/结束地址
0x2C	写 GRAM	开始写入像素数据
0x29	开启显示	退出睡眠模式，正常显示
LCD 地址映射（FSMC 如何控制 RS 引脚）
本实验将 LCD 的 RS 引脚 接在 FSMC 的 A6 地址线 上，通过访问不同的内存地址来控制 RS 电平：

c
// LCD 结构体定义（来自 lcd.h）
typedef struct {
    volatile uint16_t LCD_REG;   // RS = 0（写命令）
    volatile uint16_t LCD_RAM;   // RS = 1（写数据）
} LCD_TypeDef;

// 基地址计算（NE4 + A6）
#define LCD_BASE  (0x6C000000 | ((1 << 6) * 2 - 2))  // = 0x6C00007E
#define LCD       ((LCD_TypeDef *)LCD_BASE)
当执行 LCD->LCD_REG = 0x2C 时，FSMC 硬件自动将 A6 地址线拉低（RS=0），LCD 识别为命令；
当执行 LCD->LCD_RAM = 0xFFFF 时，A6 地址线拉高（RS=1），LCD 识别为数据。

8080 时序与 FSMC 的对应关系
8080 信号	FSMC 引脚	说明
CS	FSMC_NE4	片选（Bank1 子 Bank4）
RS	FSMC_A6	命令/数据选择（通过地址线控制）
WR	FSMC_NWE	写使能（低电平有效）
RD	FSMC_NOE	读使能（低电平有效）
D0~D15	FSMC_D0~D15	16 位数据总线
BL	PB15	背光控制（普通 GPIO，不属于 FSMC）

显存与窗口的关键点
TFTLCD 自带 GRAM：2.8 寸屏（240×320）每个像素 16 位，GRAM 大小 = 240×320×2 = 153600 字节。

窗口设置：通过 lcd_set_window 设置显示区域，后续写入的像素数据自动填充到窗口内。

光标移动：lcd_set_cursor 设置下一个像素的写入位置，配合 lcd_write_ram_prepare 完成单点写入。

④ 中断/DMA 机制
目标：理解 TFTLCD 驱动是否使用中断或 DMA。

本实验的中断/DMA 方案：无中断，无 DMA，纯 CPU 轮询
机制	是否使用	说明
中断	否	FSMC 工作在异步模式，CPU 主动发起读写操作，无中断响应。
DMA	否	未使用 DMA 传输，所有数据由 CPU 通过 LCD->LCD_RAM 写入，效率虽低但代码简单。
与 OLED 实验的对比
维度	OLED（I2C 模拟）	TFTLCD（FSMC）
通信方式	GPIO 模拟 I2C	FSMC 硬件 8080 并行总线
数据总线宽度	1 位（SDA）	16 位（D0~D15）
时钟来源	软件延时（delay_us）	FSMC 硬件时序（基于 HCLK）
CPU 介入频率	每 1 bit 都需要 CPU 翻转	每次 16 位写入只需一条 = 语句
刷屏速度	慢（约 10ms/屏）	快（约 0.5ms/屏）
为什么不用 DMA？
本实验为学习目的，使用最简单的 CPU 写入方式。实际项目中可开启 FSMC 的 DMA 模式，将显存数据自动搬运到 LCD，释放 CPU 做其他任务。

⑤ 改参实验
目标：通过修改参数验证对 TFTLCD 驱动和 FSMC 的理解。

改参实验 1：修改 FSMC 时序参数（提速/降速）
操作：在 lcd_init() 中，将 fsmc_write_timing_struct.DataSetupTime 从 3 改为 1（最快）或 10（最慢）。

现象：

DataSetupTime = 1：刷新速度变快，但屏幕可能出现雪花或花屏（时序太紧，LCD 反应不过来）。

DataSetupTime = 10：刷新变慢，但显示更稳定。

结论：时序参数需根据 LCD 驱动芯片型号 和 PCB 走线长度 调整，找到速度和稳定性的平衡点。

改参实验 2：修改屏幕扫描方向（画面翻转）
操作：在 lcd_scan_dir() 中，修改 regval 的 bit 5~7，或直接在 lcd_display_dir() 后调用不同的扫描方向。

现象：文字/图片上下颠倒或左右镜像。

结论：0x36 寄存器的 bit 5~7 控制行列扫描方向，可用于适配不同的安装方向。

改参实验 3：修改像素格式（颜色深度）
操作：在 lcd_ex_st7789_reginit() 中，将 0x3A 寄存器的值从 0x05（RGB565）改为 0x06（RGB666，18 位色）。

现象：颜色显示异常或图片颜色偏色（因为 16 位颜色值无法正确映射到 18 位）。

结论：像素格式必须与 lcd_draw_point 传入的颜色值格式一致，否则颜色会失真。

改参实验 4：修改背光亮度（PWM 控制）
操作：将 PB15 配置为 TIMx 的 PWM 输出，并修改占空比。

代码示例：在 lcd_init() 中增加 PWM 初始化，然后通过 __HAL_TIM_SET_COMPARE() 调节亮度。

现象：背光亮度随占空比变化，0% 全暗，100% 最亮。

结论：背光控制独立于显示内容，可通过 PWM 实现无极调光。
