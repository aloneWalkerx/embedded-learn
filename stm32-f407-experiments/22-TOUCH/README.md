# 实验 22：触摸屏

本实验通过 STM32F407 驱动 **2.8寸电阻触摸屏**，实现触摸坐标的采集与显示。实验涵盖了**模拟 SPI 通信、ADC 采样、五点校准算法、EEPROM 参数存储**等核心技术。

### ② 寄存器级

> **目标**：从寄存器层面理解触摸屏的工作原理。

#### 电阻触摸屏硬件原理

```
四线电阻触摸屏结构：

  ┌─────────────────────────────────────────┐
  │  X+  ←─── 上导电层（ITO） ───→  X-    │
  │         ↑                              │
  │         │ 触摸时两层接触               │
  │         ↓                              │
  │  Y+  ←─── 下导电层（ITO） ───→  Y-    │
  └─────────────────────────────────────────┘

测量 X 坐标：在 X+ 和 X- 之间加电压 → 从 Y+ 读取电压
测量 Y 坐标：在 Y+ 和 Y- 之间加电压 → 从 X+ 读取电压
```

### ③ 数据流

> **目标**：理清从“触摸按下”到“LCD 显示坐标”的完整数据流。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    电阻触摸屏完整数据流                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【硬件层】                                                                 │
│                                                                             │
│  手指触摸屏幕 → 两层 ITO 接触 → T_PEN 引脚被拉低（中断信号）               │
│                                                                             │
│  【ADC 采样层】（模拟 SPI）                                                 │
│                                                                             │
│  ① CS 拉低（选中 XPT2046）                                                 │
│  ② 发送 0x90（X 通道命令）→ 等待 6µs → 读取 12 位 X 物理值（0~4095）      │
│  ③ 发送 0xD0（Y 通道命令）→ 等待 6µs → 读取 12 位 Y 物理值（0~4095）      │
│  ④ CS 拉高（释放芯片）                                                     │
│                                                                             │
│  【滤波层】（排序 + 去极值 + 平均）                                         │
│                                                                             │
│  ① 连续读取 5 次 X/Y 值                                                    │
│  ② 对数据升序排列                                                          │
│  ③ 去掉最大值和最小值（去除噪声）                                          │
│  ④ 取中间 3 个值的平均值                                                   │
│  ⑤ 连续读取 2 次，偏差在 ±50 范围内才算有效                                │
│                                                                             │
│  【坐标转换层】（应用校准参数）                                             │
│                                                                             │
│  物理坐标（0~4095）→ 屏幕坐标（0~239/0~319）                               │
│  x = (物理_x - xc) / xfac + 宽度/2                                        │
│  y = (物理_y - yc) / yfac + 高度/2                                        │
│                                                                             │
│  【应用层】（main.c）                                                       │
│                                                                             │
│  if (tp_dev.sta & TP_PRES_DOWN) {                                           │
│      lcd_draw_point(tp_dev.x[0], tp_dev.y[0], RED);  // 画点               │
│  }                                                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 坐标转换原理（五点校准法）

```
物理坐标（AD 值）             屏幕坐标（像素）
    (0, 4095)                    (0, 0)
        │                           │
        │   ┌──────────────────┐    │
        │   │   校准矩阵        │    │
        │   │  x = (AD_x - xc)  │    │
        │   │      / xfac + W/2 │    │
        │   │  y = (AD_y - yc)  │    │
        │   │      / yfac + H/2 │    │
        │   └──────────────────┘    │
        │                           │
    (4095, 0)                    (239, 319)
```

### ④ 中断/DMA 机制

> **目标**：理解触摸屏的检测与扫描方式。

#### 本实验的方案：**无中断，无 DMA，纯轮询**

| 机制      | 是否使用 | 说明                              |
| ------- | ---- | ------------------------------- |
| **中断**  | 否    | 使用轮询方式检测 T_PEN 引脚电平，每 10ms 扫描一次 |
| **DMA** | 否    | 数据量小（每次读 2 个 12 位值），无需 DMA      |

#### 与电容屏的对比

| 对比项      | 电阻屏（本实验）    | 电容屏        |
| -------- | ----------- | ---------- |
| **检测方式** | 轮询 T_PEN 引脚 | 中断 + 轮询    |
| **通信协议** | 模拟 SPI      | I2C        |
| **坐标读取** | 发送命令读 ADC 值 | 直接读寄存器     |
| **校准**   | 需要五点校准      | 不需要        |
| **多点触摸** | 不支持         | 支持（5~10 点） |
