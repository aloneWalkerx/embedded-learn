# 实验 11：USMART调试

本实验通过 STM32F407ZGT6 的 **FSMC 外设**（Flexible Static Memory Controller），串口助手，利用 **8080 并行接口** 驱动 2.8 寸 TFTLCD 彩屏（驱动芯片 **ST7789**），通过USMART测试TFTLCD的彩色文字、图形、数字、中文等的显示功能。

### ② 寄存器级

> **目标**：从寄存器层面理解 USMART 组件涉及的硬件配置。

#### 串口接收相关寄存器

| 寄存器            | 作用      | 本实验配置                       |
| -------------- | ------- | --------------------------- |
| **USART1_CR1** | 控制寄存器 1 | 使能接收（RE=1）、接收中断（RXNEIE=1）   |
| **USART1_SR**  | 状态寄存器   | 读取 RXNE 标志判断是否收到数据          |
| **USART1_DR**  | 数据寄存器   | 读取接收到的字节                    |
| **NVIC**       | 中断控制器   | 使能 USART1 中断，抢占优先级 3，子优先级 3 |

#### 定时器相关寄存器（用于 runtime 统计）

| 寄存器          | 作用       | 本实验配置                             |
| ------------ | -------- | --------------------------------- |
| **TIM4_CR1** | 控制寄存器 1  | 使能计数器（CEN=1），向上计数模式               |
| **TIM4_PSC** | 预分频寄存器   | 1000 - 1（84MHz → 84kHz）           |
| **TIM4_ARR** | 自动重装载寄存器 | 1000 - 1（84kHz → 84Hz → 约 1ms 中断） |
| **TIM4_SR**  | 状态寄存器    | UIF（更新中断标志）                       |
| **TIM4_CNT** | 计数器寄存器   | 实时计数值，用于 runtime 计时               |

#### USMART 的命令解析流程（软件层面）

| 步骤  | 操作                                   | 关键函数                                                        |
| --- | ------------------------------------ | ----------------------------------------------------------- |
| ①   | 定时器中断触发，调用 `usmart_scan()`           | `TIM4_IRQHandler` → `usmart_scan`                           |
| ②   | 检查串口接收完成标志 `g_usart_rx_sta & 0x8000` | `usmart_get_input_string`                                   |
| ③   | 提取函数名和参数                             | `usmart_cmd_rec` → `usmart_get_fname` + `usmart_get_fparam` |
| ④   | 在函数名列表中查找匹配函数                        | 遍历 `usmart_nametab[]`                                       |
| ⑤   | 根据参数个数调用函数指针                         | `usmart_exe` → 函数指针数组调用                                     |
| ⑥   | 打印返回值                                | `USMART_PRINTF`（即 `printf`）                                 |



### ③ 数据流

> **目标**：理清从“串口发送命令”到“函数执行并返回结果”的完整链路。

┌──────────────────────────────────────────────────────────────────────────────┐
│                    USMART 完整数据流（串口 → 函数 → 返回）                  │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【PC 端】                                                                   │
│                                                                              │
│  用户输入：lcd_clear(RED) + 回车                                             │
│       │                                                                      │
│       ▼                                                                      │
│  【串口硬件层】                                                              │
│                                                                              │
│  ① USART1 接收每个字符 → 触发接收中断                                       │
│  ② 中断服务函数将字符存入 g_usart_rx_buf[]                                   │
│  ③ 收到 0x0D（回车）时，置位 g_usart_rx_sta 最高位（接收完成标志）          │
│                                                                              │
│  【定时器中断层（1ms）】                                                     │
│                                                                              │
│  ④ TIM4 更新中断 → 调用 usmart_scan()                                       │
│  ⑤ usmart_scan 检测到 g_usart_rx_sta 最高位为 1                             │
│  ⑥ 调用 usmart_get_input_string() 获取命令字符串                             │
│                                                                              │
│  【命令解析层】                                                              │
│                                                                              │
│  ⑦ usmart_cmd_rec()                                                         │
│     │   ├── usmart_get_fname() → 提取函数名 "lcd_clear"                    │
│     │   │   └── 在 usmart_nametab[] 中查找匹配                              │
│     │   └── usmart_get_fparam() → 提取参数 "RED"                           │
│     │       └── usmart_str2num() → 将 "RED" 转换为数值 0xF800              │
│  ⑧ 若函数未找到 → 打印 "未找到匹配的函数!"                                  │
│  ⑨ 若参数错误 → 打印 "参数错误!"                                            │
│                                                                              │
│  【函数执行层】                                                              │
│                                                                              │
│  ⑩ usmart_exe()                                                             │
│     │   ├── 根据参数个数进入对应 case（1 个参数）                           │
│     │   │   └── res = (*func)(temp[0])                                     │
│     │   └── 若开启了 runtime，记录执行时间                                  │
│  ⑪ 打印执行结果                                                            │
│     │   ├── 有返回值 → "lcd_clear(0XF800)=0X0000;"                         │
│     │   └── 无返回值 → "lcd_clear(0XF800);"                                │
│                                                                              │
│  【PC 端】                                                                   │
│                                                                              │
│  ⑫ 串口助手显示执行结果                                                     │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘



### ④ 中断/DMA 机制

> **目标**：理解 USMART 组件的中断机制。

#### 本实验的中断方案

| 中断类型            | 触发条件            | 回调/处理函数                           | 作用                  |
| --------------- | --------------- | --------------------------------- | ------------------- |
| **USART1 接收中断** | 串口收到一个字节        | `USART1_IRQHandler` → 存入缓冲区       | 接收 PC 端发送的命令字符串     |
| **TIM4 更新中断**   | TIM4 计数器溢出（1ms） | `TIM4_IRQHandler` → `usmart_scan` | 定时扫描串口缓冲区，执行命令解析与调用 |

#### 与前面实验的中断对比

| 实验                | 中断类型                        | 中断频率           | 主要用途                |
| ----------------- | --------------------------- | -------------- | ------------------- |
| 实验 5（基本定时器）       | TIM6 更新中断                   | 可配置（如 500ms）   | 周期性任务调度             |
| 实验 6（PWM 输出）      | 无中断（纯硬件输出）                  | -              | 生成 PWM 波形           |
| 实验 7（输入捕获）        | TIM5 捕获中断 + 更新中断            | 每个边沿触发         | 测量信号脉宽              |
| 实验 8（脉冲计数）        | TIM2 更新中断（溢出时）              | 约 65535 个脉冲    | 扩展计数范围              |
| **实验 10（USMART）** | **USART1 接收中断 + TIM4 更新中断** | **每个字节 + 1ms** | **接收串口命令 + 定时扫描执行** |

> **核心特点**：USMART 使用 **双中断协同** 机制——USART 中断负责数据接收，TIM 中断负责命令处理，两者解耦，避免了在串口中断中执行耗时解析操作，保证了系统实时性。
