# 实验 13：PVD电压监控

本实验通过 STM32F407ZGT6 的 **PVD（Programmable Voltage Detector，可编程电压检测器）** 功能，实时监测芯片供电电压 VDD。当电压低于设定的阈值时，触发中断并执行紧急处理（如点亮 LED、LCD 显示报警、保存关键数据等）。PVD 是系统级“电压哨兵”，能为产品提供可靠的掉电预警机制。

#### 与前面实验的时钟对比

| 实验             | 核心外设    | 主要时钟源          | 用途            |
| -------------- | ------- | -------------- | ------------- |

### ② 寄存器级

> **目标**：从寄存器层面理解 PVD 的工作原理。

#### PVD 相关寄存器

| 寄存器           | 作用         | 本实验配置                              |
| ------------- | ---------- | ---------------------------------- |
| **PWR_CR**    | 电源控制寄存器    | 配置 PVD 阈值（PLS[2:0]）、使能 PVD（PVDE=1） |
| **PWR_CSR**   | 电源状态寄存器    | 读取 PVDO 标志位（0=电压正常，1=电压低于阈值）       |
| **EXTI_IMR**  | 外部中断屏蔽寄存器  | 使能 Line 16（PVD）中断                  |
| **EXTI_RTSR** | 上升沿触发选择寄存器 | 配置电压上升时触发中断                        |
| **EXTI_FTSR** | 下降沿触发选择寄存器 | 配置电压下降时触发中断                        |

#### 电压阈值对照表

| 阈值宏定义            | 对应电压     | 典型应用场景               |
| ---------------- | -------- | -------------------- |
| `PWR_PVDLEVEL_0` | 2.1V     | 极低电压预警（仅剩最后处理时间）     |
| `PWR_PVDLEVEL_1` | 2.2V     | 电池供电设备低电量预警          |
| `PWR_PVDLEVEL_2` | 2.3V     | 锂电池保护电压附近            |
| `PWR_PVDLEVEL_3` | 2.4V     | 通用低电压预警              |
| `PWR_PVDLEVEL_4` | 2.5V     | 3.3V 系统掉电预警（推荐）      |
| `PWR_PVDLEVEL_5` | 2.6V     | 提前预警（有足够时间保存数据）      |
| `PWR_PVDLEVEL_6` | 2.7V     | 高阈值预警                |
| `PWR_PVDLEVEL_7` | **2.9V** | **本实验使用**（最高阈值，最早预警） |

### ③ 数据流

> **目标**：理清从“电压变化”到“LCD 显示报警”的完整链路。

┌──────────────────────────────────────────────────────────────────────────────┐
│                    PVD 完整数据流（电压 → 中断 → 显示）                     │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【硬件检测层】（纯硬件自动运行）                                            │
│                                                                              │
│  VDD 电压变化 → PVD 比较器持续比较 → PVDO 标志位更新（PWR_CSR 寄存器）     │
│       │                                                                      │
│       ├── VDD > 2.9V → PVDO = 0（正常）                                    │
│       │                                                                      │
│       └── VDD < 2.9V → PVDO = 1（过低）                                    │
│                                                                              │
│  【中断触发层】（电压跨越阈值时触发）                                         │
│                                                                              │
│  PVDO 发生变化（0→1 或 1→0）→ EXTI Line 16 检测到边沿                      │
│       │                                                                      │
│       ▼                                                                      │
│  NVIC 中断控制器 → PVD_IRQn 中断请求                                        │
│       │                                                                      │
│       ▼                                                                      │
│  跳转到 PVD_IRQHandler（中断向量表）                                         │
│                                                                              │
│  【HAL 库处理层】                                                             │
│                                                                              │
│  PVD_IRQHandler → HAL_PWR_PVD_IRQHandler                                    │
│       │                                                                      │
│       ├── 清除 EXTI Line 16 中断标志位                                      │
│       │                                                                      │
│       └── 调用 HAL_PWR_PVDCallback()（用户回调）                             │
│                                                                              │
│  【用户应用层】                                                               │
│                                                                              │
│  HAL_PWR_PVDCallback()                                                       │
│       │                                                                      │
│       ├── if (PVDO == 1)                                                    │
│       │   ├── LED1(0)          // 点亮 LED1 报警                            │
│       │   └── LCD 显示红色 "PVD Low Voltage!"                              │
│       │                                                                      │
│       └── else (PVDO == 0)                                                  │
│           ├── LED1(1)          // 熄灭 LED1                                │
│           └── LCD 显示蓝色 "PVD Voltage OK! "                              │
│                                                                              │
│  【主循环】（独立运行，不受干扰）                                             │
│                                                                              │
│  LED0 每 200ms 闪烁一次，指示程序正常运行                                    │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

### ④ 中断机制

> **目标**：理解 PVD 的中断配置与执行流程。

#### PVD 中断配置

| 配置项   | 值                                | 说明            |
| ----- | -------------------------------- | ------------- |
| 中断线   | EXTI Line 16                     | PVD 专用中断线     |
| 中断向量  | PVD_IRQn                         | 中断向量表中的名称     |
| 触发模式  | `PWR_PVD_MODE_IT_RISING_FALLING` | 上升沿和下降沿都触发    |
| 抢占优先级 | 0                                | 最高优先级（保证紧急响应） |
| 子优先级  | 0                                | 最高子优先级        |

#### 中断触发条件

| 电压变化方向              | PVDO 变化 | 中断触发  | 回调中执行             |
| ------------------- | ------- | ----- | ----------------- |
| VDD 从高到低（2.9V→2.8V） | 0 → 1   | ✅ 触发  | LED1 亮，LCD 显示红色报警 |
| VDD 从低到高（2.8V→3.0V） | 1 → 0   | ✅ 触发  | LED1 灭，LCD 显示蓝色正常 |
| VDD 稳定不变            | 不变      | ❌ 不触发 | -                 |

#### 与其他实验的中断对比

| 实验             | 中断类型                | 触发频率          | 主要用途           |
| -------------- | ------------------- | ------------- | -------------- |
| 实验 5（基本定时器）    | TIM6 更新中断           | 可配置（如 500ms）  | 周期性任务调度        |
| 实验 7（输入捕获）     | TIM5 捕获中断           | 每个边沿触发        | 测量信号脉宽         |
| 实验 11（RTC）     | RTC 闹钟中断 + 唤醒中断     | 按设置触发 + 1秒    | 时间匹配提醒 + 周期性任务 |
| **实验 12（PVD）** | **EXTI Line 16 中断** | **电压跨越阈值时触发** | **电压异常紧急处理**   |

> **核心特点**：PVD 中断是**异步的、不可预测的**，只在电压异常时触发，必须设置为最高优先级以保证及时响应。
