# 实验 21：SPI通信

本实验通过 STM32F407 的 **SPI1** 接口与板载 **W25Q128 NOR Flash** 芯片进行通信，实现数据的写入与读取。通过本实验，深入理解 SPI 协议的**四线制、全双工、主从模式、四种工作模式**等核心概念，以及 NOR Flash 的**页编程、扇区擦除、读-改-写**等操作原理。

### ③ 数据流

> **目标**：理清 SPI 读写 W25Q128 的完整流程。

#### W25Q128 常用指令

| 命令             | 指令码    | 说明                     |
| -------------- | ------ | ---------------------- |
| **写使能**        | `0x06` | 使能写操作（写入/擦除前必须发）       |
| **写禁用**        | `0x04` | 禁用写操作                  |
| **读数据**        | `0x03` | 从指定地址读取数据              |
| **页编程**        | `0x02` | 向指定页写入数据（最多 256 字节）    |
| **扇区擦除**       | `0x20` | 擦除 4KB 扇区（★ 最常用）       |
| **块擦除**        | `0xD8` | 擦除 64KB 块              |
| **全片擦除**       | `0xC7` | 擦除全部芯片（耗时 30~50 秒）     |
| **读状态寄存器**     | `0x05` | 读取状态寄存器（判断 BUSY 位）     |
| **读 JEDEC ID** | `0x9F` | 读取 3 字节 ID（0xEF 40 17） |

#### 写操作完整流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    W25Q128 写操作完整流程                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ① CS = 0（选中 Flash）                                                    │
│  ② 发送 0x06（写使能命令）                                                 │
│  ③ CS = 1（取消选中）                                                     │
│                                                                             │
│  ④ CS = 0（再次选中）                                                      │
│  ⑤ 发送 0x20（扇区擦除命令）                                               │
│  ⑥ 发送 24 位地址（要擦除的扇区地址）                                     │
│  ⑦ CS = 1（取消选中）                                                     │
│                                                                             │
│  ⑧ 等待状态寄存器 BUSY 位变为 0（等待擦除完成，约 30~150ms）              │
│                                                                             │
│  ⑨ CS = 0                                                                  │
│  ⑩ 发送 0x06（写使能命令）                                                 │
│  ⑪ CS = 1                                                                  │
│                                                                             │
│  ⑫ CS = 0                                                                  │
│  ⑬ 发送 0x02（页编程命令）                                                 │
│  ⑭ 发送 24 位地址（要写入的地址）                                          │
│  ⑮ 发送 N 个字节数据（最多 256 字节）                                     │
│  ⑯ CS = 1                                                                  │
│                                                                             │
│  ⑰ 等待状态寄存器 BUSY 位变为 0（等待编程完成，约 1~3ms）                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
```

### ④ 中断/DMA 机制

> **目标**：理解本实验的通信方式。

#### 本实验的方案：**无中断，无 DMA，纯 CPU 轮询**

| 机制      | 是否使用 | 说明                          |
| ------- | ---- | --------------------------- |
| **中断**  | 否    | SPI 通信使用轮询方式，等待 TXE/RXNE 标志 |
| **DMA** | 否    | 数据量小（每次读写最多几 KB），无需 DMA     |

#### 与 IIC 的对比

| 对比项      | IIC（模拟） | SPI（本实验）           |
| -------- | ------- | ------------------ |
| **通信方式** | 半双工     | **全双工**            |
| **等待机制** | 等待 ACK  | **等待 TXE/RXNE 标志** |
| **应答机制** | 有 ACK   | **无**              |
| **中断**   | 无       | 无                  |
| **DMA**  | 无       | 无                  |

### ⑤ 改参实验

#### 改参实验 1：修改 SPI 通信速率

**操作**：在 `norflash_init()` 中修改 `spi1_set_speed()` 参数。

```
// 修改前（21MHz）
spi1_set_speed(SPI_BAUDRATEPRESCALER_4);
// 修改后（42MHz，最快）
spi1_set_speed(SPI_BAUDRATEPRESCALER_2);
// 修改后（10.5MHz，更稳定）
spi1_set_speed(SPI_BAUDRATEPRESCALER_8);
```

**现象**：速率越高，读写越快，但需确保 Flash 能稳定工作。

**结论**：W25Q128 最高支持 104MHz，42MHz 可稳定工作。

---

#### 改参实验 2：修改写入地址

**操作**：在 `main.c` 中修改写入地址。

```
// 修改前（Flash 末尾）
norflash_write(g_text_buf, flashsize - TEXT_SIZE, TEXT_SIZE);
// 修改后（Flash 开头）
norflash_write(g_text_buf, 0, TEXT_SIZE);
```

**现象**：写入位置改变，读取时需使用相同地址。

**结论**：Flash 支持任意地址读写（但需按扇区对齐擦除）。

---

#### 改参实验 3：修改工作模式（模式 0）

**操作**：在 `spi1_init()` 中修改模式配置。

```
// 修改前（模式 3）
g_spi1_handle.Init.CLKPolarity = SPI_POLARITY_HIGH;
g_spi1_handle.Init.CLKPhase = SPI_PHASE_2EDGE;
// 修改后（模式 0）
g_spi1_handle.Init.CLKPolarity = SPI_POLARITY_LOW;
g_spi1_handle.Init.CLKPhase = SPI_PHASE_1EDGE;
```

**现象**：通信可能失败（W25Q128 支持模式 0 和模式 3，需匹配）。

**结论**：主从机模式必须一致。
