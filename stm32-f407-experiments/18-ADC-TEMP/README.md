# 实验 18：内部温度传感器

本实验通过 STM32F407ZGT6 的 **ADC1 通道 16（内部温度传感器）**，采集芯片内部温度，并通过 LCD 实时显示温度值。内部温度传感器利用 **PN 结的温度特性**，将温度变化转换为电压变化，再由 ADC 转换为数字量。**无需任何外部元器件**，即可测量芯片温度。

### ① 时钟树

> **目标**：理解内部温度传感器的时钟配置。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    STM32F407 时钟树（内部温度传感器）                         │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  APB2（84MHz）→ ADC1 预分频器（/4）→ 21MHz → ADC1 核心                     │
│                                                                              │
│  ADC1 通道 16（内部温度传感器）                                              │
│       │                                                                      │
│       ├── 内部连接：温度传感器输出 → ADC1_IN16                              │
│       ├── 无需外部引脚、无需 GPIO 配置                                      │
│       └── 唯一限制：只能使用 ADC1！                                         │
│                                                                              │
│  温度传感器参数：                                                           │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │ V25（25℃ 电压）  = 0.76V（典型值）                                 │    │
│  │ Avg_Slope（斜率） = 2.5 mV/℃（典型值）                             │    │
│  │ 测量范围         = -40℃ ~ 125℃                                   │    │
│  │ 建议采样时间     = 480 周期（ADC_SAMPLETIME_480CYCLES）            │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

#### 与外部 ADC 采集的对比

| 对比项         | 外部 ADC 采集             | 内部温度传感器（本实验）                      |
| ----------- | --------------------- | --------------------------------- |
| **ADC 外设**  | ADC2 / ADC3           | **必须用 ADC1**                      |
| **通道号**     | 外部通道（如 1）             | **通道 16（ADC_CHANNEL_TEMPSENSOR）** |
| **信号来源**    | 外部引脚（如 PA1）           | **内部 PN 结**                       |
| **GPIO 配置** | 需要配置为模拟输入             | **不需要配置 GPIO**                    |
| **接线**      | 需要接电位器/传感器            | **不需要任何外部接线**                     |
| **计算公式**    | 电压 = ADC × 3.3 / 4095 | **温度 = (电压 - V25) × 400 + 25**    |

    ### ② 寄存器级

> **目标**：从寄存器层面理解内部温度传感器的配置。

#### 内部温度传感器相关寄存器

| 寄存器            | 位/字段           | 本实验配置                        | 说明                      |
| -------------- | -------------- | ---------------------------- | ----------------------- |
| **ADC1_CR1**   | **EOCIE**      | 0（不使用中断）                     | 轮询模式                    |
| **ADC1_CR2**   | **CONT**       | 0（单次转换）                      | 温度变化慢，无需连续转换            |
| **ADC1_CR2**   | **EXTEN**      | 0（软件触发）                      | 软件启动转换                  |
| **ADC1_CR2**   | **TSVREFE**    | **1（必须置位！）**                 | ★ 使能温度传感器和 VREFINT      |
| **ADC1_SQR3**  | **SQ1[4:0]**   | `ADC_CHANNEL_TEMPSENSOR`（16） | 规则序列第 1 个转换的通道          |
| **ADC1_SMPR1** | **SMP16[2:0]** | `ADC_SAMPLETIME_480CYCLES`   | 温度传感器需要较长采样时间（≥ 17.1µs） |

#### 温度传感器通道特性

| 通道        | 连接对象                 | 说明            |
| --------- | -------------------- | ------------- |
| **通道 16** | **内部温度传感器（V_SENSE）** | **只能使用 ADC1** |
| 通道 17     | 内部参考电压（VREFINT）      | 用于校准          |
| 通道 18     | 备用电池电压（VBAT）         | 测量 VBAT 引脚电压  |

### ③ 数据流

> **目标**：理清“芯片温度 → 电压 → ADC 值 → 温度值”的完整数据流。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    内部温度传感器完整数据流                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【物理层】（芯片内部）                                                    │
│                                                                             │
│  芯片温度变化 → PN 结电压变化（2.5mV/℃）                                  │
│       │                                                                      │
│       ├── 25℃ → 0.76V                                                     │
│       ├── 50℃ → 0.70V（电压降低）                                         │
│       └── 0℃  → 0.82V（电压升高）                                         │
│                                                                             │
│  【ADC 硬件层】（自动完成）                                                │
│                                                                             │
│  模拟电压（0.5~0.9V）→ ADC1 通道 16 → 12 位数字值（0~4095）              │
│       │                                                                      │
│       └── 转换时间：492 / 21MHz ≈ 23.4µs                                 │
│                                                                             │
│  【软件处理层】（CPU 计算）                                                │
│                                                                             │
│  ① ADC 值（0~4095）→ 电压值（0~3.3V）                                    │
│     voltage = (ADC / 4095) × 3.3                                          │
│       │                                                                      │
│       ▼                                                                      │
│  ② 电压值 → 温度值（℃）                                                  │
│     temperature = (voltage - 0.76) × 400 + 25                             │
│       │                                                                      │
│       ▼                                                                      │
│  ③ 温度值 → 整数（扩大 100 倍）                                           │
│     temperature_x100 = (int16_t)(temperature × 100)                       │
│                                                                             │
│  【显示层】                                                                 │
│                                                                             │
│  整数部分：temperature_x100 / 100                                          │
│  小数部分：temperature_x100 % 100                                          │
│  最终显示：XX.XX℃                                                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### ④ 中断/DMA 机制

> **目标**：理解内部温度传感器的数据采集方式。

#### 本实验的方案：无中断，无 DMA，纯轮询 + 均值滤波

| 机制       | 是否使用   | 说明                                      |
| -------- | ------ | --------------------------------------- |
| **中断**   | 否      | 使用 `HAL_ADC_PollForConversion` 轮询等待转换完成 |
| **DMA**  | 否      | 温度变化缓慢，无需 DMA                           |
| **均值滤波** | ✅ 10 次 | 消除随机噪声，提高精度                             |

#### 与外部 ADC 轮询的对比

| 对比项        | 外部 ADC（实验 14） | 内部温度传感器（本实验）        |
| ---------- | ------------- | ------------------- |
| **采集方式**   | 单次轮询          | **10 次均值滤波**        |
| **CPU 占用** | 每次 ~23µs      | **每次 ~234µs（10 次）** |
| **数据稳定性**  | 可能跳动          | **稳定（滤波后）**         |
| **适用场景**   | 快速变化的信号       | **缓慢变化的温度**         |

> **为什么 10 次循环没问题？** 温度采集总耗时仅 **234µs**，而主循环每 100ms 执行一次，CPU 占用率 < 0.3%，完全无影响。

### ⑤ 改参实验

#### 改参实验 1：修改均值滤波次数

**操作**：在 `adc_get_temperature()` 中修改 `times` 参数。

```
// 修改前（10 次）
result = adc_get_result_average(ADC_CHANNEL_TEMPSENSOR, 10);
// 修改后（50 次）
result = adc_get_result_average(ADC_CHANNEL_TEMPSENSOR, 50);
```

**现象**：温度值更稳定（跳动更小），但采样速度变慢（50 × 23.4µs = 1.17ms）。

**结论**：均值滤波次数越多，数据越稳定，但响应越慢。

#### 改参实验 2：修改采样时间

**操作**：在 `adc_channel_set()` 中修改采样时间参数。

```
// 修改前（480 周期，精度最高）
adc_channel_set(&g_adc_temperature_handle, ADC_CHANNEL_TEMPSENSOR, 1, ADC_SAMPLETIME_480CYCLES);
// 修改后（84 周期，速度较快）
adc_channel_set(&g_adc_temperature_handle, ADC_CHANNEL_TEMPSENSOR, 1, ADC_SAMPLETIME_84CYCLES);
```

**现象**：采样速度变快，但温度值可能不稳定（温度传感器输出阻抗高，需要较长采样时间）。

**结论**：温度传感器建议使用 **480 周期**采样，以保证精度。

#### 改参实验 3：手动加热/冷却芯片

**操作**：用手指触摸芯片表面，或用酒精棉擦拭芯片。

**现象**：

- 手指触摸 → 温度上升 5~10℃

- 酒精棉擦拭 → 温度迅速下降

**结论**：内部温度传感器可实时反映芯片温度变化。

#### 改参实验 4：读取 Flash 校准值（提高精度）

**操作**：从 Flash 中读取 V25 和 Avg_Slope 校准值。

```
// STM32F4 在 Flash 中存储了校准值（只读）
uint16_t *p_v25 = (uint16_t *)0x1FFF75A8; // V25 校准值
uint16_t *p_avg_slope = (uint16_t *)0x1FFF75AA; // Avg_Slope 校准值
// 计算公式改为使用校准值
voltage = ((double)result * 3.3) / 4095;
temperature = (voltage - (*p_v25 / 1000.0)) / (*p_avg_slope / 1000.0) + 25;
```

**现象**：温度测量精度提高（从 ±3℃ 提升到 ±1.5℃）。

**结论**：使用 Flash 校准值可获得更高精度。
